平台概览

沃衡汽车能碳管理平台面向生产基地的能源计量、经营活动数据、组织碳核算、监测告警、报告导出和减排绩效管理。平台通过设备采集、业务台账、排放因子、核算模型和报告材料形成闭环，支撑能碳管理人员、能源运维人员、体系与核查支持人员开展日常工作。

本手册用于系统演示和操作说明。演示数据使用「沃衡汽车泰州生产基地」和「沃衡汽车湖州生产基地」两个租户，两个租户共用同一套功能体系，数据、设备、区域、台账和核算结果相互隔离。

绿色工厂评价功能主线

平台首页围绕绿色工厂评价关注的十二类能力组织入口，覆盖能源消费管理、组织温室气体核算、产品碳足迹、供应链碳管理、碳核查支撑和碳资产管理。

  • 能耗查询：按基地、区域、设备、能源品种和时间维度查询能源消费数据。
  • 能源消费质量和强度计算：形成综合能耗、能源品种汇总和单位产出、单位面积等强度指标。
  • 能源消费分析与用能策略推荐：识别用能结构、时段趋势、重点系统和策略建议。
  • 能效对标：对设备、工序和管理单元开展能效指标对标。
  • 能流分析：展示计量边界、分项用电和关键用能链路。
  • 能量平衡：维护计量边界、边界成员，形成边界输入、分项归集和差异诊断。
  • 用能与碳排放预算管理：维护年度目标、月度预算和执行跟踪。
  • 碳排放核算：支撑组织边界、核算边界、Scope 1/2/3 和 ISO 14064 分类核算。
  • 碳足迹核算：维护产品研究、系统边界、生命周期阶段、活动清单和核算结果。
  • 供应链碳管理：管理供应商档案、填报任务、数据审核、证据材料和披露记录。
  • 碳核查支撑：组织核查项目、凭证材料、问题处理、审核日志和报告导出。
  • 碳资产管理：展示公开碳价行情、成本情景测算和减排项目绩效跟踪。

演示租户

泰州生产基地重点展示整车装配、厂内物流、MQTT 电表接入、分区分项用能监测和告警闭环。湖州生产基地重点展示零部件制造、经营活动台账、非电活动数据导入、组织碳核算、报告导出和减排绩效。

两个租户都具备完整的区域、设备、活动数据、因子、核算结果、报告、减排项目和告警数据。演示时可先使用泰州说明采集和监测，再切换湖州说明台账、核算和报告。

推荐讲解顺序

  • 从首页进入，确认品牌、租户和功能导航。
  • 查看能源运营入口与菜单，说明首页工作台、数据管理入口页和左侧侧边栏之间的关系。
  • 打开态势大屏，说明能耗、碳排和区域运行总览。
  • 进入区域、设备与 MQTT 电表接入配置，说明区域层级、设备台账、测点映射和点位监测。
  • 进入能源主数据维护，说明能源种类和单位换算。
  • 进入能源事实数据维护，说明手工录入、CSV 导入、详情回显、编辑、导出和删除。
  • 进入能源运营查询与分析，说明能耗查询、能耗强度、用能分析、能流分析、能效对标和能量平衡。
  • 进入经营活动台账和活动数据导入，说明非电数据维护。
  • 进入因子库，说明因子来源、版本和计算因子启用。
  • 进入组织碳，说明边界、Scope、ISO 14064 分类、明细和碳流。
  • 进入监测告警，说明规则、事件和处理留痕。
  • 进入核查与报告，说明凭证、导出和减排绩效跟踪。
