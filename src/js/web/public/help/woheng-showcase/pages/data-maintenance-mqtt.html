区域、设备与 MQTT 电表接入配置

本章说明自动计量数据的维护闭环。对象关系为：区域承载设备，设备承载测点，MQTT 表计绑定到设备，MQTT 点位映射把报文来源 Tag 转换为平台测点，测试报文处理成功后形成点位读数，并进入点位监测和电表电量统计。

菜单位置

区域、设备与 MQTT 接入配置涉及三个侧边栏一级菜单：

  • 从「组织档案 / 监测区域」进入 /data/monitor-area，维护生产基地、车间、仓储区、装卸区、充电区、能源站等区域层级。
  • 从「设备与测点 / 设备台账」进入 /data/terminals，维护设备、设备测点、MQTT 表计绑定和 MQTT 点位映射。
  • 从「设备与测点 / 点位监测」进入 /data/point-monitoring，查看测点实时值、历史趋势和来源追溯。
  • 从「设备与测点 / 电表电量」进入 /data/meter，查看电表聚合后的用电量和采集统计。

本章只处理自动计量链路。能源种类、单位换算和账期能源事实数据分别在“能源主数据维护”和“能源事实数据维护”章节处理。

对象边界

  • 区域：维护生产基地、车间、仓库、能源站、充电区等空间层级，用于设备挂载、分区分项用能和告警定位。
  • 设备：维护电表、配电柜、制冷机组、输送线、充电桩等业务设备，用于承载采集协议、采集标识、能源类型和投运状态。
  • 设备测点：维护设备上的平台测点，例如正向有功总电能、有功功率、温度、压力等，用于监测、统计和告警。
  • MQTT 表计绑定：维护外部网关、表计编号和平台设备之间的绑定关系。
  • MQTT 点位映射：维护报文来源 Tag 与平台测点之间的转换关系。
  • 接入测试：发送测试报文并查看处理结果，确认绑定和映射能够生成平台读数。

区域维护

进入 /data/monitor-area。在区域树中选择父级区域，点击“新增子区域”，填写区域编码、区域名称、区域类型、负责人、归属部门、位置说明和备注。保存后，新区域应出现在区域树中。

点击“编辑区域”，调整区域名称、负责人、归属部门、位置说明或备注。编辑表单应回填原有字段，保存后在区域详情中回显更新后的名称、层级、状态和设备统计。

点击“停用”，区域详情应显示停用后的状态。停用用于暂停区域参与后续业务选择，不删除已有历史数据。

删除区域前，页面会校验是否存在子区域或已挂载设备。无子区域、无设备后，点击“删除”并确认，区域树和接口回读中不再出现该区域。

设备维护

进入 /data/terminals，点击“新增设备”。填写设备编码、设备名称、所属区域、设备类型、资产编码、采集标识、厂家、型号、归属部门、维护负责人、能源类型、采集协议、在线状态、投运状态和位置说明。对于 MQTT 电表，所属区域、采集协议、采集标识和能源类型是后续采集归集的关键字段。

保存后按设备编码查询并打开设备详情。详情页应显示基础信息、所属区域、设备类型、采集配置、能源类型、启用状态、投运状态和关联测点。

点击“编辑”，调整设备名称、维护负责人、备注或其他主数据字段。编辑表单应回填原字段，保存后设备详情和列表应显示更新结果。

设备支持停用和恢复。停用后设备不再作为正常运行设备参与展示；恢复后设备重新进入启用状态。删除设备前需要先清理子设备、测点和 MQTT 绑定。

清理关联对象后点击“删除”并确认，设备列表和接口回读中不再出现该设备。

设备测点维护

在设备详情中切换到“测点”页签，点击“新增测点”。填写测点编码、测点名称、数值类型、单位、来源字段、采样周期、启用状态、告警启用、上下限和备注。测点应挂载在当前设备下。

点击测点行内“编辑”，调整测点名称、来源字段或备注。编辑表单应回填原字段，保存后测点列表显示更新后的业务名称和来源字段。

点击测点行内“删除”，测点列表和接口回读中不再出现该测点。删除测点前，应确认该测点不再被 MQTT 映射或告警规则引用。

MQTT 表计绑定

在设备详情中切换到“接入”页签，点击“配置表计绑定”。选择接入通道，填写网关标识、表计编号、匹配名称、外部设备号、临时地址、绑定状态、换算方式和倍率。保存后，当前设备应显示 MQTT 数据源、订阅主题、网关/表计、绑定状态和倍率配置。

点击“编辑绑定”，可调整临时地址、匹配名称、绑定状态、换算方式或倍率。保存后，绑定记录应在接入页签和接口中回显更新结果。

删除表计绑定前，应先删除其下的点位映射。删除绑定后，设备接入页签回到未绑定状态。

MQTT 点位映射

表计绑定完成后，点击“新增映射”。填写来源 Tag、平台测点、测点名称、来源名称、单位、倍率、版本和启用状态。保存后，映射列表应显示“来源 Tag -> 平台测点”的转换关系。

点击映射行内“编辑”，可调整来源名称、单位、倍率、版本或启用状态。保存后，映射记录应回显更新结果。

点击映射行内“删除”，映射列表和接口回读中不再出现该映射。删除映射后，该来源 Tag 不再参与平台测点投影。

接入测试与采集结果

完成表计绑定和点位映射后，点击“发送测试报文”。结果态应显示 MQTT 测试报文已处理，并能看到入站消息状态、处理结果和投影后的测点读数。若测试报文被拒绝，页面会显示拒绝原因，需按来源 Tag、测点编码或倍率配置重新调整后再测试。

进入 /data/meter，查看最新采集、采样数、电表数量和用电趋势。该页面用于说明 MQTT 采集数据已经进入电表统计口径，并能按时间和设备形成电量统计。

进入 /data/point-monitoring，按设备、点位或来源编码搜索关键测点，查看总点位、有效点位、超时未更新点位、点位列表、趋势图、最近读数和来源追溯。演示时可选择正向有功总电能，说明读数已经从 MQTT 接入链路进入实时监测，并保留设备编码、网关、表计、订阅主题和映射版本等追溯信息。

既有数据展示

除新增验证数据外，设备台账中还保留生产基地已有设备示例，可用于展示演示租户下的设备主数据、采集协议和接入状态。

区域主数据页可用于展示生产基地已有区域层级、基础信息和本区域设备分布。

覆盖结论

  • 区域 CRUD 已覆盖：新增、详情回显、编辑、停用、删除。
  • 设备 CRUD 已覆盖：新增、详情回显、编辑、停用、恢复、删除。
  • 设备测点 CRUD 已覆盖：新增、编辑、回显、删除。
  • MQTT 表计绑定 CRUD 已覆盖：新增、保存后回显、编辑、删除。
  • MQTT 点位映射 CRUD 已覆盖：新增、保存后回显、编辑、删除。
  • 接入测试已覆盖：测试报文处理、点位读数生成、点位监测和电表电量查看。

当前边界

本章覆盖设备侧自动计量接入闭环。MQTT 接入通道源和订阅主题的维护属于接入通道管理配置，当前手册按演示租户已有接入通道执行。
