核查材料与报告导出

核查材料和报告导出用于把组织碳核算结果整理为可归档、可复核、可支撑外部沟通的材料。

碳核查支撑工作台

进入 /carbon/verification，选择核查项目，查看核查项目状态、证据资料、核查工作、质量问题和审核日志。

核查凭证与材料

切换到「证据资料」页签，查看凭证清单、凭证数、文件和下载入口。该页面用于说明活动数据与凭证资料之间的关联。

报告导出

切换到「报告与材料」和「报告导出」页签，查看报告导出记录和下载入口。导出的组织温室气体盘查报告可用于企业归档、复核、核查支撑材料准备和披露材料编制。

检查项

  • 先选择真实核查项目，再展示证据和报告。
  • 报告导出应展示结果态或导出记录。
  • 凭证清单应能说明文件、活动数据和核查工作的关联。
