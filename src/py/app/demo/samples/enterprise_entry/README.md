# 沃衡工厂2026年10月录入案例

本目录的企业名称、设备记录和全部数量均为合成演示数据。案例仅借鉴企业常见原表的结构：电量与电费分列，设备用气按月记录，柴油按领用单汇总，制冷剂按维修工单记录。客户名称、联系人、原始生产数量和内嵌图片未复制到本目录。

## 输入文件

- `泰州基地_能源导入.csv`、`湖州基地_能源导入.csv`：可直接上传到能源数据维护页。使用与该页下载模板一致的8个中文列：区域、设备、能源种类、月份、能源用量、单位、费用、备注。企业无需填写内部编码或数据来源字段。首次导入新增记录；重复上传提示冲突，不覆盖已有值。
- `*_能源月结.csv`：同值原始台账，供手工录入和金额核对。天然气单位使用系统字典中的 `m3`，即立方米。
- `*_制冷剂维修.csv`、`*_通勤运输.csv`：业务原表。它们不是温室气体导入模板，不能直接上传到温室气体工作簿导入入口。对应的 `*_制冷剂填报.xlsx`、`*_员工通勤填报.xlsx`、`*_入厂运输填报.xlsx` 由当前后端正式模板导出后填充，可直接上传到对应分类。每个文件仅显示活动数据表；首次导入后在活动记录中选择企业因子库中的对应演示因子。

所有CSV采用UTF-8 BOM编码和真实换行。原始台账与能源导入文件由测试逐行核对期间、数量和费用，设备与区域名称取自同一份主数据目录。

## 工厂、对象与期间

泰州和湖州分别属于独立演示租户。报告期编号为 `WOHENG-TZ-ENTRY-202610`、`WOHENG-HZ-ENTRY-202610`，期间为2026年10月1日至31日。能源活动由能源事实按月生成；不会过滤来源来避开同一期间的真实重叠数据。

备用发电机的零值表示本月已核实停机且没有领油，不表示缺失。备用发电机属于固定燃烧源，柴油叉车属于移动燃烧源。

办公楼多联式空调使用 `REFRIGERANT-01`，位于 `OFFICE`。10月12日，泰州补充R32为2.4 kg，湖州为1.8 kg。10月24日，泰州回收1.2 kg，湖州回收0.8 kg，当日均没有补充或已确认泄漏，因此活动量为0。额定充注量18 kg保留为设备属性，不参与本期活动量计算。演示假设将维修补充量作为此前已发生的泄漏量；没有维护事件的月份不生成记录。

自驾通勤采用本月实际出勤22天、每天2次单程、1人的样例。泰州单程18 km，合计792人·km；湖州单程16 km，合计704人·km。既有员工通勤模型不含报告期，不能把其未注明期间的里程自动重复用于每个报告期，本案例直接使用注明期间的分类活动记录。

10月18日零部件入厂运输各1次。泰州运输12 t、单程160 km，活动量1920 t·km；湖州运输10 t、单程120 km，活动量1200 t·km。

## 编排和验收

`seed_enterprise_entry()`先配置能源排放源，再通过能源导入用例新增缺失的本包记录；中断安装遗留且尚未核算的本包事实，采用与能源页面相同的维护校验显式更新。随后调用统一能源活动生成服务、活动维护服务、企业因子库选择服务和既有核算用例。再次安装保留事实和活动ID；已核算案例与样例不一致时只报错，已有锁定状态或核算引用的未完成案例也不覆盖。

`validate_enterprise_entry()`核对输入数量、单位、费用、对象、日期、来源事实集合及最终核算结果。集成测试在独立PostgreSQL容器中连续执行两次安装和校验，另验证未知来源记录与临时设备不被清理。

本包旧月度制冷剂活动没有维修事件的月份归档；旧核算快照保留。旧反填能源事实仅按当前沃衡租户及本包来源标记清理。未知来源和其他租户不参与修复。

整包验收使用现有产品、价格、产量及资源绑定记录检查生产分母，不要求旧设备作业量表达到固定条数。设备运行小时或单位作业量对标仍需要相应业务记录；没有记录时保持缺少分母状态，不按有电量的时段虚构运行小时。员工自驾通勤按人公里填报，不据此反推企业汽油消耗，因此汽油不列为本包必需能源。

运行小时派生调整的依据、功能影响及包级验收范围见[实现记录](implementation-notes.md)。当前两租户运行小时未提供，未宣称完整能效对标；包级 `completed` 不表示全部模块数据齐备。
