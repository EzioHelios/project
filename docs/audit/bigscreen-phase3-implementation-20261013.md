## 查询与交互

- `GET /api/bigscreen/events`：category=all/power/carbon/video，start/end、status、area、page；每页10条。起止日期包含结束当天。
- 统计总数、类型分布、区域分布、状态分布和列表均使用同一查询条件。空数据不伪装为接口成功后的模拟数据。
- 缺失区域/设备关联保留为未关联，不通过设备名称或告警正文补关系。SQL关联同时限定team_id。
- 切换租户重新挂载事件面板，清除详情和筛选状态；请求缓存按租户、条件隔离。
- 弹窗列表单独限高，长事件正文换行，分页保持可见。图表完成标记后才保存截图。
