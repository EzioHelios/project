## 2. 实现约束与修复

- 电表差分继续生成逐设备、逐区域的能源事实；大屏仍称“电表电量合计”，不冒称仓库购电总量。
- Scope 2 电表候选汇总必须有 active、import、include_in_scope2 的显式边界，并满足有效日期；模拟区间不进入实测候选汇总。
- 删除“完全没有边界就默认全表参与”的兜底。边界被停用/移除时退役旧投影，不继续保留已失效的候选量。
- 月投影替换完整选定范围；源读数改为无效后，不保留上版已失效的区间事实。
- 两端示值中任意一个无效，区间不计量；不拿无效示值作为下一个区间的基点。
- 同一电表存在多个本月有效边界时拒绝执行，要求消除歧义，不按排序取最后一条。
- 无有效边界且无组织碳活动依据时，现有汇总状态为 incomplete，不将缺配置包装成 ready。
- 计算版本升级为 boundary_v3，沿用既有版本化投影和租户会话；未新增业务表、总分表猜测规则或演示数据。
- 投影使用租户级事务锁，整月事实、归集与运行结果一次提交。失败保留执行记录但回滚业务写入；再次执行使用独立尝试编码。只复用最近有效运行，避免数据改回旧值时误用已经退役的历史结果。
- MQTT worker 按队列加载依赖，不再因报告导出依赖缺失而无法启动采集。
- 预测训练移出异步事件循环；容器 worker 的 OpenMP/OpenBLAS 线程默认1，可通过 WORKER_NUMERIC_THREADS 配置。未修改预测公式、默认数据或采集频率。

### 不应混同的状态

1. 祥泰电表能源事实可以计算，不代表总分表不重叠已经确认。当前电表合计不能直接变成仓库购电总量。
2. 云集采集返回 HTTP 429，本轮采集提前停止。旧采集任务仍报告 completed，因此必须看采集错误日志，不能只看任务绿灯。本轮聚合成功是对已入库读数成功计算，不是云集实时采集验收通过。
3. 定时增量筛选当前依据读数ID水位；修改既有读数、修改边界、修改区域挂载后需要显式重算受影响月份。跨月迟到读数影响下月基点的自动失效传播尚未覆盖，不能宣称任意历史更正都会自动重算。
4. MQTT规范化为UTC无时区值，云集历史时间的时区约定仍需核查。本轮未对整库时间统一加8小时，也未把采样显示时间当作已经校准的现场时间。
5. 安方已有8条边界被沿用，其性质为分项计量；本轮没有取得足以证明全仓覆盖且不重叠的现场资料。
