## 1. 结论与范围

可以做组件级复刻，而且不需要重建大屏框架。应该复刻原版的业务内容、信息密度、图示和主题布局，再利用现有租户隔离、能源事实、组织碳核算和园区模型完善交互。不能把原版的硬编码计算、静态状态或历史数据直接包装为实时能力。

本清单覆盖 **54 个展示/交互项**：公共层10项、总览10项、视频8项、电能10项、碳能10项、现版扩展6项。它们不是54个独立React组件；总览与专题页复用同一组业务组件及数据查询。原版远程报表未恢复的部分以代码/接口确认内容为准，不能宣称已取得完整原版视觉配置。

### 2.1 接入前的最小数据处理

1. 复用已有MeterReadingFact -> 计量边界 -> EnergyIntervalFact投影链路，查明为什么读数持续而能源事实停在8月；不新建大屏电量表。
2. 安方核定8个计量设备与其余8条设备的角色，检查现有边界；祥泰建立实际计量边界。不得将总表和分表同时累计为仓库总量。
3. 统一历史`purchased_electricity`与当前`electricity`的业务筛选映射、版本和粒度；禁止把旧quantity字段和register差分重复累加。
4. 电量、发电量、上网电量分别核对设备/寄存器定义。反向电量本身不能自动等于光伏发电，更不能自动从购电里扣掉。
5. 刷新现有幂等投影后验证同一期间总量、区域、设备的闭合关系；这是计算验收，不新增“来源确认/对账”业务页面。
6. 组织碳继续走现有活动数据、参数、归集、核算批次；祥泰67条活动不能视作已有67条有效核算结果。

## 3. 组件判定规则

- **A 可接**：已有对应档案/事实，可直接读取或常规筛选统计；仍须处理空值及验收，历史不自动变成实时。
- **B 需归集**：基础事实存在，需要修复现有投影或补聚合查询；不新增业务事实来源。
- **C 需补条件**：需补设备分类、ID映射、参数、业务定义或接入配置后才能展示。
- **D 待取证**：本次查到的当前应用数据不足以支撑该项，不代表客户现场没有设备或旧备份绝无数据。
- **不照搬**：旧指标/实现语义不成立，不能以视觉复刻为由恢复错误。

以下状态只用于开发清单，不直接作为客户产品文案。空值不替换成0；真实查询得到0可以显示0。

工程约束：

1. 在现`components/bigscreen/charts.tsx`及bigscreen样式层收敛公共option构建，不让各路由再定义一套轴、tooltip、色板。颜色表示固定业务含义，不因排名变化换色。
2. 图表高度来自面板布局，不能使用一律260px的内部默认高度挤压内容。容器真正可见且尺寸非零后初始化；收起/切页/窗口变化触发resize。ECharts官方支持容器变化后resize，见[Chart Container](https://echarts.apache.org/handbook/en/concepts/chart-size/)。
3. 图表点击/图例操作可用ECharts事件与action实现，见[Event and Action](https://echarts.apache.org/handbook/en/concepts/event/)。按ID传递对象，不按显示名反查设备。
4. 字体不随viewport随意缩小。1920画布下先保证轴字、图例、字段可读；不够放先减少重复面板。1440与4K按完整画布比例适配并实测。
5. 面板区域底色足够实，GIS底图不会穿透干扰标签；保留原版蓝色框线和专用图示，但不加新装饰光团/假3D柱。
6. 曲线数据缺口明确保留；小时、日、月按相应事实聚合，不用平滑插值生成不存在的采样。平滑视觉也不能越过缺测点。
7. 数据契约中保留period、unit、observed_at、coverage、source_kind与业务ID，组件渲染不计算排放、不解析字符串拼出的数值。
8. 截图等待关键接口成功、图表渲染完成、动画结束与图像加载；先监听完成状态再触发渲染，避免错过事件后死等。连续两帧布局稳定才取证，不只固定sleep。

- 对同一个仓库/期间核查总量、排行、趋势；区域未归集单列；小时/日不重复累计，总分表不重复相加。
- 原始采样、聚合时间、画面刷新三种时间各自可查；历史告警不标实时。
- 真实切换两仓、日/月/年、区域、电能类型；图表、KPI、地图/列表选中保持一致。
- 视频播放验证有效帧连续变化；关闭识别后仍播放，切换/离页释放连接；不能用一张识别JPEG当实时流。
- 碳核算按有效批次和方法取值；不重复累计重算批次；没有分母/基期/归集时不硬算强度/同比/区域值。
- 1920×1080逐页整体截图，辅以1440与4K布局检查；图表单点、全0、空、长标签、大值、缺测、错误态分别验收。
- 旧页无法加载的远程报表标待取证；现页图片/视频无效标无效，不用占位图当复刻完成。

本轮产物是清单和只读证据，不包含线上修复、数据生成、页面重构或提交。
