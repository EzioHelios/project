# 祥泰组织碳盘查报告内容与版式修订验收

## 本轮范围

修改组织盘查报告渲染器及报告内容装配，未新增台账或数据库实体。仅在本地18101验证，未提交代码或部署线上；工作区其他演示、能源等改动未纳入本轮。

- 删除报告正文中的内部报告号、运行号、活动编号、参数代码、证据代码及重复状态/版本表。
- 删除参数与活动记录对应表。参数只列一次，保留名称、值、单位、正式来源、版本、地区、年份、引用位置及适用活动类别。
- 原60条活动记录不删除。附表按真实设备身份与月份汇总为10行、6个月，附设备小计和月度合计；零值仍为0，未采集月份为横线。单位、活动类别分别分组；跨月记录保留完整期间，不人为摊月。
- 设备归属和比例取核算运行的 allocations 快照，名称经租户会话查询现有设备；提交报告时仍固定完整正文上下文。缺归属显示待补充，比例不完整阻止导出，避免重复计算或遗漏。
- 设备贡献合并同设备跨类别的碳当量，不合并不同设备的同名记录。气体汇总不把CO2E当作气体种类展示。
- 资料索引区分因子来源文件和活动凭证，不再将正式因子文件反复列为60条活动记录已复核。
- 设施主体不展示关联企业档案信用代码为自身法人代码；移除以数据库创建时间冒充编制日期的映射。保留真实草稿状态，编制签署资料缺失仍用【待补充】。

## 排版依据

参考已收集的《天津七一二通信广播股份有限公司产品碳足迹核查报告》第4页的文字排版，实测PDF正文SimSun 14磅、标题15/14磅、数字Times New Roman。只参考视觉样式，不采用其产品生命周期边界或核查结论，也不称其为官方组织报告模板。

输出采用A4纵向、宋体14磅正文、宋体加粗标题、10.5磅表格、黑白图表。去掉重复页眉，封面不显示页码；目录含章节书签与PAGEREF页码域。月度趋势直接显示年月，计量对象名称、贡献横条、数值与占比同列。

## 真实样本及验证

- 本地祥泰仓库，报告`RPT-1069-2082`第1版，草稿；期间2025-07-01至2025-12-31。未使用旧WAREHOUSE-GHG演示报告。
- 10个计量对象、60条月度数据，电量31,380.66 kWh；因子0.5827 kgCO2/kWh；计算结果18,285.510582 kgCO2e。报告展示18.2855 tCO2e，不改变计算精度。
- 从实际应用数据库`fullstack-spa-db-1`按明确祥泰租户读取活动/归集/设备记录，与Word表格逐格比对，60个设备月份单元格、10个设备小计、6个月合计和总计均一致。
- 本地内置浏览器完成正文修改、保存、重开确认和Word实际下载。只修改报告文字，没有重跑核算或写入原始计量/活动数据。
- Word由原生`/Applications/LibreOffice.app/Contents/MacOS/soffice`转换PDF。交付Word另经同一soffice刷新并缓存目录页码后保存，再次转PDF验收。
- 最终10页逐页目视检查；目录页码3/4/5/7/9/9/10/10正确，无空白页、越界文字或数字拆行。字段更新后前5页像素一致，后5页重新检查。
- 字体检查确认中文为嵌入的SimSun，拉丁文字为Times New Roman；部分数学符号使用LucidaGrande。没有原版本的ArialUnicode/Carlito标题替代。
- 技能自带渲染器在此机器上使用的字体环境不能正确呈现中文，其初轮产物不交付；最终验收全部使用上述原生soffice，未修改系统字体。
- 30项集中单元/集成测试通过，覆盖渲染、身份及期间、正文快照、核查导出链、设备快照、同名设备、单位隔离、分摊比例、零值及跨月记录。相关Python文件Ruff通过，`git diff --check`通过。未执行全仓库测试。
