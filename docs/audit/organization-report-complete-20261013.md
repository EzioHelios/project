# 组织碳盘查报告实现及祥泰导出验收

## 实现边界

沿用前置《组织碳盘查报告样本筛选与系统字段映射-20261013》审查结论，参考本地 ISO 14064-1:2018 第9章和附录F组织正文。不是把产品碳足迹报告或核查声明改名使用。沿用既有报告、企业档案、主体、报告期、边界、活动、参数、证据模型，没有新增业务表或第二套台账。

本轮只在本地开发和验证，未提交代码、未部署线上。工作区原有 demo/能源/微电网等改动保留，不纳入本轮完成声明。

## 填写入口与字段映射

| 内容 | 维护入口 | 存储/导出 |
| --- | --- | --- |
| 企业名称、信用代码、单位、行业、运营地址、面积、人员 | `/data/company` 编辑资料 | 既有 EnterpriseInfo 字段 |
| 注册地址、法定代表人、联系人、企业概况、业务过程 | 同上 | EnterpriseInfo.other_info 明确白名单字段 |
| 报告主体与企业关联、主体类型 | `/carbon/organization/boundary` 报告主体编辑 | ReportingOrganization.enterprise_id/organization_type；服务校验租户 |
| 报告期、基准年 | 同上，报告期编辑 | ReportingPeriod；基准年允许清空，校验整数年份 |
| 本期目的、使用者、编制责任、边界理由、基准年政策、监测方法、缺失处理、质量管理、不确定性、结果分析、减排措施 | `/carbon/organization/reports` 编辑 | GhgInventoryReport.content_snapshot.narrative，11项白名单；草稿/退回可编辑 |
| 标准、边界方法、设施纳入/排除 | 既有标准配置和边界维护 | 报告所选 profile/boundary/facilities，不默认套工业企业标准 |
| 活动量、单位、期间、结果 | 既有分类填报、核算运行 | 选择运行的结果；多气体结果对同一活动量去重，不重复相加 |
| 方法、公式、因子数值/单位/版本/地区/年份 | 既有方法与参数维护 | formula_snapshot、GhgParameterAssignment 及 snapshot；参数名称来自方法参数定义 |
| 原始凭证与因子文件 | 既有证据关联、参数证据引用 | 活动证据、因子文件分别映射；因子文件不能替代活动原始凭证验收 |
| 月度趋势、源贡献、活动明细、参数对应关系 | 自动派生 | 直接采用所选运行结果；无随机图表、无额外核算算法 |

正文不足的字段使用【待补充】。不自动填写签名、核查通过、不确定度或零排放结论。

## 快照与导出约束

- 提交/重新提交时将完整 reportContext 固定到现有 content_snapshot；非草稿导出使用该内容，不再读取当前企业资料覆盖历史正文。
- 当前状态单独反映报告生命周期。草稿不会显示“已发布”。
- 旧版已提交/已发布报告若没有完整正文快照，返回明确错误，需从原核算运行生成新版本再走提交流程；未用当前数据回填冒充历史快照。此为发布前必须告知的行为变化。
- 核查材料出口复用同一组织报告装配器；核查项目只添加自己的材料复核状态与核查发现，并保留报告的因子文件索引。
- 本轮没有完成所有历史报告快照迁移，也没有宣称所有行业、清除/生物源、股权比例设施分摊、同比/强度等扩展场景已完整验证。

## 祥泰样本

- 本地租户：祥泰仓库；期间：2025-07-01 至 2025-12-31。
- 报告：`RPT-1069-2082` v1，草稿；核算运行：`CALC-D7D9833727194FFF`。
- 10个既有计量对象、60条月度记录，电量31,380.66 kWh；引用江苏省2023年电力二氧化碳因子0.5827 kgCO2/kWh，来源文件为生态环境部、国家统计局2025年第47号公告附件。
- 结果18,285.510582 kgCO2e，即18.285510582 tCO2e。报告明确为所列设备计量范围，不将没有确认的其他类别补成零。
- 生成前核对活动所引小时事实的存在、非重复ID、measured/current状态、电量合计和设备区域关联。未以旧 WAREHOUSE-GHG 演示报告作为导出来源。
- 企业身份、地址、面积等读取既有企业档案，尚不等于完成工商资料和现场档案真实性核验。原始凭证/校准及签署等不足在报告内保留【待补充】。
- 为完成本地样本，既有维护工具从能源事实整理了2025年60条、2026年90条活动。本次只核算并导出2025年；2026年本地数据与线上覆盖量不同，不声称已同步两端。
- 核对备份目标时发现 `local-before.dump` 来自未被当前应用使用的旧容器库，不能当成此次实际库的变更前备份。当前应用实际连接本机18102端口 `fullstack-spa-db-1`；已另保存 `actual-db-after.dump` 的GHG及边界相关表，性质为变更后快照。本轮未删除旧报告或改动线上数据库。
