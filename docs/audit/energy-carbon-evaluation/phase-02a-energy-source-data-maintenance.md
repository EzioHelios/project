# 第二阶段 A：能源来源数据维护主线

## 审查边界

本阶段只处理能源数据来源维护，不处理强度分母、经营活动台账、组织碳活动数据、碳核算转换、对账和电力口径重构。

能源数据维护主线收敛为：

`区域/设备/测点/MQTT 配置 -> 自动计量读数 -> 能源区间事实`

`手工录入/CSV 导入 -> 能源区间事实`

后续能源分析页面只消费能源事实数据，不在本阶段新增旁路表、旁路入口或兼容旧客户品牌流程。

## 本阶段不处理项

| 项目 | 处理方式 |

| 经营活动台账 | 放入经营数据阶段；不作为能源录入主线的一部分 |
| 组织碳活动数据 | 放入 P4；后续再实现从能源事实生成碳活动数据的幂等动作 |
| 电力主账、对账、来源确认 | 当前维持现状，不在本阶段改口径 |
| 自动计量重算入口 | 后续结合电表投影链路单独复核，不在本阶段新增旁路向导 |
