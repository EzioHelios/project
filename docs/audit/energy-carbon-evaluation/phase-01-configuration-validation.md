## 验证范围

本记录补充第一阶段页面整改后的实操验证，重点确认配置功能是否真实可用，而不只判断页面是否存在。

验证对象：

- 设备台账：设备建档、设备编辑、测点新增、测点编辑、接入校验、质量检查。

## 当前判断

区域、设备、测点维护和预警规则配置已经具备“页面承载 + 接口保存 + 编辑回读”的基础闭环。基于租户已有 MQTT 接入通道，新建设备可以在设备详情页签内完成 MQTT 表计绑定、点位映射和测试报文投影；接入通道源和订阅主题维护未纳入本轮验证，已在 `phase-01a-area-device-maintenance.md` 单独记录。

告警中心已具备统一入口和基础动作。视频告警关闭有效；设备告警完整链路需要补充一条可重复生成、可恢复的未处理设备告警样本，或将告警生成流程纳入数据采集/规则触发验证。

正式演示源当前仍使用 `WOHENG_DEMO_MQTT_USERNAME`、`WOHENG_DEMO_MQTT_PASSWORD` 环境变量管理 broker 凭据。本地未设置对应变量时，长期运行的 MQTT worker 会跳过正式演示源订阅；本次 broker 级验证使用临时无凭据数据源完成并已清理。

## 后续补强

1. 为设备告警增加可重复验证样本，覆盖确认、转工单、关闭和处理历史。
2. 补充告警中心的正式工单详情、附件、责任人、转派和审核验证。
3. 将正式演示环境的 MQTT broker 地址和凭据环境变量纳入部署检查，避免 worker 因缺少凭据跳过订阅。
4. 将数据质量问题的补录、忽略、重算和对能耗/碳核算的阻断关系纳入后续整改。
