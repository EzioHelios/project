# 两仓大屏主体完整展示调整清单

日期：2026-10-13。状态：方案，尚未实施本清单中的页面重编排、档案补录或发布。

## 目标与约束

按用户最新要求，不再以机械恢复旧版54项为目标，而以两仓每个主题页有完整、真实、有独立业务意义的主体内容为目标。

- 没有可用数据源的摄像头、光伏实时值、储能实时值不占据主屏等待补齐；改用有依据的内容，并调整标题。
- 企业/仓库介绍可以采用有来源的公开资料；公开建设资料与当前采集、核算数据分别展示。
- 优先复用主系统的查询服务、核算结果及图表，不另建大屏事实或计算模型。
- 不扩展报告期、Scope、同比、审批、来源确认等交互。保留现有期间能力即可，内部确保所选数据一致。
- 本清单的“替换”是明确的版面设计，不是运行时静默fallback。不用另一租户的数据填补当前租户，不搭通用组件配置平台。
- 各租户允许模块不同。宁可减少面板、扩大有效图表，也不画重复图或长期空白框来凑数量。

实施时明确替换路由/导航引用，不保留两套重复页面或重定向兼容壳；既有AI视觉独立路由和后端能力不删除、不自动启动识别。

## 实施顺序

1. 主体重编排：确定四主题及两仓固定内容清单，删除重复与长期空面板，将视频主屏改为设备运行监测。
2. 共用图表与服务：先碳流，后电量归集流；两者与现有主系统保持同源，只适配大屏尺寸和皮肤。能流服务先完成上述最小纠正。
3. 补齐有效主体：设备监测板、排放源排行、活动/因子摘要；复用现有查询，不增加事实实体。
4. 档案补充：公开企业背景和祥泰建设特色，保留来源/日期，处理冲突；安方缺精确参数不成为主屏落地阻塞。
5. 内置浏览器逐页验收：两仓四页及辅助页；1920/1440截图、同页前后比较，确认图表完成、长名称可读、无旧品牌和跨租户内容。
