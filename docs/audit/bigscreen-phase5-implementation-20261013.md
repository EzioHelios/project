## 复用与纠正

- 能流复用`EnergyFlowQueryService`，图表复用主系统`createSankeyChartOption`，适配大屏尺寸和颜色。
- 共享服务原有人工拼接的转换、分配、损失路径改为事实中的能源、区域、设备归集路径；无损耗测量不生成损失诊断。
- 不同能源单位不混加。复盘使用中文对象名称及实际单位，不显示内部节点ID。
- 电量只取当前版本、计量来源、非模拟、kWh、电表分类事实，与现有KPI条件一致，不叠加日/月/小时事实。
- 碳流调用主系统`GhgAnalyticsQueryService.flow`，源排行和归集排行取同一批次、同一范围二方法；没有新建因子、公式、核算、审批实体。
- 设备按区域ID分组，不凭名称推断位置；采样读数、期间电量、台账状态分别表达。
- 删除无消费者的大屏摄像头目录查询与字段；摄像头配置、安全预警来源及独立视觉业务接口不变。

## 保留问题

1. **安方既有因子名为“安方中心库演示电网电力因子”，0.5703kgCO2e/kWh。**未改成官方因子或重新核算；正式汇报前需确认来源、适用年度、批准参数。祥泰因子也只是读取既有核算快照，并非本轮审定。
2. 祥泰总分表、独立光伏和储能配置未补猜，电量仍称电表合计，不称已确认的总进线购电量。
3. 未采样设备保留相应标记，不把设备档案数当作在线数。
4. 没有接通真实摄像头或补GIS绑定；未知视频源不再作为主屏空框。
5. 完成的是本轮四主题主体清单，不宣称旧项目54项全部等价完成，也不宣称客户历史数据已经全部校核。
