# 视觉作业接入实施与验证记录

日期：2026-09-20。本文记录本轮实现，不替代同日 `material-handling-vision-integration-20260920.md` 对源仓库的审查结论。

## 已实现

- `/bigscreen/vision` 接入既有大屏布局、导航和租户切换，展示真实检测画面、观测统计、分时作业时长、任务关联与记录确认。
- `/data/video` 沿用摄像头台账，增加识别配置：RTSP、检测阈值、时间窗口、区域、设备和物资任务。配置按版本保存，历史记录保留原任务快照。
- `VideoMonitor` 保存识别配置和最新运行画面；租户隔离的 `VisionObservation` 保存观测片段、模型 hash、任务快照和 JPEG 证据。确认后关联现有 `MaterialHandlingOperation`，没有复制源仓库的账号或业务数据库。
- 识别端使用本地视频经 FFmpeg 实时发布至 MediaMTX RTSP，由 YOLO/ByteTrack 实际推理；SQLite outbox 持久投递，事件键幂等，同一任务最多生成一条正式作业。
- 登录运行前验证，401 自动重新登录。摄像头、记录和证据受租户隔离控制；摄像头普通列表不暴露识别配置或图像二进制。

启动、停止、配置说明见 [`tools/vision/README.md`](../../tools/vision/README.md)。未修改安方、祥泰现场数据，未部署线上。

## 实际验证

本地前端端口 18101，后端 18100；租户为沃衡汽车泰州生产基地。使用源仓库 `camera_b_smooth.mp4` 与 `best.pt`，RTSP 仅监听 `127.0.0.1:18115`。

| 验证项 | 结果 |
| --- | --- |
| 视频到 RTSP 到模型推理 | 实际运行；推理帧数与 JPEG 内容持续变化，记录由模型产生 |
| 摄像头配置编辑 | 浏览器保存任务 001 到 002；识别进程按新版本重启，旧记录不被改写 |
| 观测证据 | 浏览器打开实际带检测框 JPEG，无预制事件替代 |
| 人工确认 | 浏览器分别确认两个任务，生成正式物资作业；快照与所选记录一致 |
| 幂等与隔离 | 同一记录重复确认返回同一作业；跨租户画面读取返回 404；清空会话后客户端重新登录成功 |
| 页面交互 | 修复大屏鼠标穿透导致按钮不能操作；配置、筛选、确认与证据查看均实际操作 |
| 视口 | 检查 1280×720、1440×900、1920×1080；最终截图无图表空白或表头遮挡 |
| 自动化 | 7 项后端集成测试、3 项跟踪单元测试通过；Ruff、Biome、TypeScript 检查通过 |

## 明确边界

- 当前权重只有叉车类别，不声称支持旋转吊、行吊、堆垛机识别。
- 检测的是目标移动片段，不等同于已识别完整搬运语义或自动读取物资编码。设备、物资、批次、数量由明确配置的任务提供，并经人工确认。
- 多目标、出画、断流及配置切换中止片段保留状态，不自动确认为完整任务。演示参数不作为现场准确率承诺。
- 演示视频循环产生多个真实识别片段，但相同任务不重复生成物资作业。正式作业保留演示数据质量标记，不混同现场数据。
- 大屏当前采用每秒更新的识别 JPEG，不是全帧率视频播放器。
- 配置、上报和确认当前沿用管理员权限；独立最小权限识别服务账号、现场模型精度验收和生产部署不在本轮验证范围。
- 本轮未重新验收设备能耗分配、物资碳分摊与产品碳足迹结果，不能将识别输入链路通过视为这些计算全部完成。
