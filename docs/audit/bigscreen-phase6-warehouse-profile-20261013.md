# 第六批：移除宣传首页，收敛仓库概况

日期：2026-10-13。实施环境：本地 18101。本轮未发布线上、未提交 Git。

## 改动

- 删除独立 `/bigscreen/intro` 页面和侧边栏“企业介绍”入口，不保留空壳页面。大屏默认入口仍为态势总览。
- 既有 `/carbon/page2` 导航入口改为总览，不再引用已删除页面。
- 仓库概况并入总览左上角，详细档案及实景使用同一弹窗，不新建宣传页。
- 删除企业宣传展示组件及其样式。成功案例、品牌叙事、项目轮播和内部草稿文案不再出现在四主题主屏。
- 保留已有租户隔离的档案和照片查询接口；没有增加媒体实体或新的图片导入通道。
- 祥泰使用既有区域照片，支持按区域筛选、上一张/下一张、失败重试。只按需请求当前照片，切换租户重置弹窗及图片资源。
- 安方没有已确认的现场实景，因此不显示照片占位，不借用祥泰照片。模型继续作为主视觉，概况缩小后将空间留给区域用电排行。
- 档案中的空文本、非正面积/人数不作为有效档案值显示；不影响实测电量为零、设备故障数为零等业务状态。
- 不修改能源、碳排放、设备或企业原始数据。

## 验证

- 内置浏览器验证安方、祥泰两租户的总览、运行监测、电量监控、碳排管理，共 8 个页面结果态。
- 8 个结果态均为当前租户，未发现未加载图片、宣传占位或内部草稿文本；浏览器错误日志为空。
- 祥泰 20 张图片逐一加载成功，原图宽度为 3024 或 4032 像素。验证区域筛选、翻页、关闭返回。
- 安方概况仅显示当前库名、设备和挂载区域，没有残留祥泰图片。
- 1920×1080 主屏截图；两仓额外做 1440×810 复查，概况按钮完整可见，无横向页面溢出。
- 前端大屏测试 36 项通过，覆盖租户切换关闭弹窗、区域筛选重置页码、照片失败重试、资源释放。
- 后端新增未知面积/人数不展示、无照片不生成假图片的单元测试。
- 定向后端测试 14 项通过（使用 `--no-cov`；首次带全项目覆盖率门槛运行时测试全通过，但小范围测试未达到全项目 65% 门槛）。
- TypeScript、Biome、Ruff、生产构建检查通过。构建仍有既有大包体和 Node 弃用提示。
