## 电量口径

- 以页面结束日期锚定当日、月初至该日、年初至该日，与自由选择的查询开始日期分离。
- 复用既有energy_filters：当前版本、kWh、电量类型、计量来源、非模拟、电表设备分类。
- 只统计日事实；区域过滤使用既有父子ID关系。无数据返回null，不返回0。
- 有记录天数指该范围至少一条符合条件的电表日事实；不代表每台设备全天采样完整，不用于证明总分表不重叠。
- 电量标题仍为电表合计，不称全仓购电或总进线电量。总分表边界未确认的条件继续保留。
