## 数据库字段映射

`EnergyBenchmarkProfile` 扩展为标准方案主体，新增字段：

- `library_type`：区分政策标杆库、设备能效等级库、企业内部标准库、历史基准库。
- `source_url`、`source_hash`、`source_file_name`：记录政策网页、PDF 附件 hash 和本地缓存文件名。
- `standard_code`、`version_status`：记录政策文号、标准号和版本状态。

`EnergyBenchmarkItem` 扩展为标准指标项，新增字段：

- `applicable_industry`、`applicable_category`、`applicable_condition`：记录适用行业、设备/产品分类和适用条件。
- `metric_direction`：记录指标方向，支持越低越优、越高越优、等级序。
- `advanced_value`、`saving_value`、`access_value`、`baseline_value`：记录先进、节能、准入/基准、历史基准值。
- `advanced_level`、`saving_level`、`access_level`、`standard_level`：记录设备等级或标准等级标签。
- `standard_code`、`source_url`、`source_hash`、`reference_standard`、`version_status`：记录可追溯来源。

## 页面职责

- `/data/energy-benchmark`：能效标准与标杆库维护，承担政策资料同步、标准方案 CRUD、标杆指标 CRUD、模板导入、历史基准生成。
- `/energy/benchmark`：能效对标分析工作台，只做筛选、计算展示、图表、明细和数据来源查看；主数据维护通过明确入口跳转。

## 演示数据口径

- 沃衡泰州生产基地偏设备和用能系统对标：变压器、空压机、充电桩、冷水机组、光伏逆变器、照明系统、分拣线等设备/系统需具备能耗、运行小时、作业量和标杆项。
- 沃衡湖州生产基地偏产线、产品和产值强度对标：装配线、电驱线、电池托盘线、产品、产量、价格和资源绑定需具备可计算数据。
- 两个租户都应有完整的标准方案、标杆指标、能源事实、分母事实和分析结果；展示重点可以不同，不能故意留空。

## 实现边界

- 政策库同步命令只负责下载官方网页附件、记录 hash 并写入结构化种子条目；本轮不解析全部 PDF 表格。
- 历史基线生成只写入 `enterprise_internal`，不污染 `policy_industry` 或 `equipment_efficiency`。
- 分析接口对缺能源数据、缺分母、缺标杆、单位不一致返回业务状态，不用总能耗硬算细分设备、产线或产品。
