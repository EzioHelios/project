# 大屏能源归集流图实施边界

## 既有依据

沿用[能碳标准与术语知识库](能碳标准与术语知识库.md)中已登记的GB/T 3484-2009《企业能量平衡通则》、GB/T 28749-2012《企业能量平衡网络图绘制方法》研究；本轮不重新宣称标准状态或认证结论。

## 实施含义

目前大屏使用能源事实中的能源品种、区域ID、设备ID展示归集，非完整企业能量平衡。每条事实的能源数量仅在各归集层累计一次；图中不同层级不能再相加成总能耗。同一计量边界内的总分表是否重叠，需要既有边界配置确认，本轮不从设备名称推定。

没有物理转换、输配损耗或存储变化测量时，不添加等量转换路径，不将零损耗当作测量结果。不同物理单位不得共享同一宽度尺度，需先按能源品种筛选。大屏电量明确限定kWh。

后端复用EnergyFlowQueryService，返回无损耗诊断及混合单位状态；前端标题使用“电量归集流图”。碳流只展示主系统现有核算批次，未更改任何排放公式或因子。
