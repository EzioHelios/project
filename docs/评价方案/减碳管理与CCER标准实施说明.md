# 减碳管理与 CCER 标准实施说明

## 1. 适用范围

本文约束平台“减排概览、减排项目库、方法学与 CCER”三个产品模块。系统中的三类结果必须独立存储、独立展示、独立审计：

1. 组织温室气体盘查的实际排放；
2. 按项目基准线计算的预计、监测或核查减排量；
3. 经国家登记系统登记签发的 CCER 碳资产。

项目减排量不得回写组织盘查结果；预计或内部复核结果不得生成碳资产。绿电采购仅影响组织 Scope 2 市场法结果，不自动构成 CCER。

## 2. 规范依据与实现影响

| 规范 | 状态 | 平台用途 | 实现约束 |
|---|---|---|---|
| 《温室气体自愿减排交易管理办法（试行）》 | 现行 | CCER 项目、审定核查、登记签发 | 只有 `issued` 状态可关联碳资产；系统采用离线材料台账，不代替国家登记 |
| 国家温室气体自愿减排项目方法学 | 以国家登记系统现行目录为准 | 适用性、基准线、项目排放、泄漏、监测和证据 | 正式方法学版本不可由租户修改；计算适配器按版本锁定 |
| ISO 14064-2:2019 | 现行 | 项目层面的量化、监测与报告 | 保存项目边界、基准线、附加性/适用性、监测计划、不确定性和完整输入快照 |
| ISO 14064-3:2019 | 现行 | 审定与核查 | 审定、核查与内部复核分别记录；审定和核查机构独立性受领域规则约束 |
| GB/T 33760-2017 | 现行 | 项目减排量评估通用要求 | 事前和事后计算分离，记录基准线、项目排放、泄漏、扣减与证据 |
| GHG Protocol Project Protocol | 现行参考 | 企业项目核算补充 | 用于项目边界、基准线和重复计算防控，不覆盖正式 CCER 方法学 |
| ISO 50006、ISO 50015 | 现行参考 | 企业节能措施的能源基准与绩效验证 | 内部节能项目支持产量、HDD/CDD、运行时间等归一化变量 |

## 3. 方法学目录与执行边界

迁移中固化国家登记系统公布的 18 项现行方法学目录。以下五项配置可执行 Python 适配器和确定性测试：

- CCER-01-001-V01 并网光热发电；
- CCER-01-004-V01 可再生能源电解水制氢；
- CCER-06-001-V01 既有公共建筑围护结构与供暖通风空调系统能效提升；
- CCER-14-001-V01 造林碳汇；
- CCER-14-002-V01 红树林营造。

统一结果结构为 `ER = BE - PE - LE - D`，但具体参数、适用性门槛、舍入和诊断由方法学版本对应的代码适配器决定。数据库不保存可执行表达式，不使用动态 `eval`。其余正式方法学作为可追溯目录展示，未配置适配器前只允许人工评估，不得运行正式计算。

## 4. 数据、证据和审计规则

- 基准线锁定后不可修改；调整必须新建版本。
- 计算运行冻结方法学、基准线、活动数据、因子和时间窗口。
- 监测工作簿由方法学参数模式生成，严格校验字段、单位、来源、频率和必填参数。
- 证据复用 `GhgEvidenceFile` 与 `GhgEvidenceLink`，项目只建立关联，不复制文件。
- 项目状态、版本、审批、计算和 CCER 台账变更写入 `ReductionAuditEvent`。
- 所有租户业务表使用 `TeamScopedMixin` 并启用、强制 PostgreSQL RLS。

## 6. 声明边界

平台提供标准化、可审计的项目管理与量化工作流，不宣称替代具有资质的第三方审定或核查，也不直接连接或写入国家登记系统。正式签发量以登记系统和签发文件为准。
