# 能源强度产品产量与产值分母设计

## 目标

`/energy/intensity` 当前只覆盖面积强度。下一阶段补齐“单位产品综合能耗、单位产值/增加值综合能耗”时，不应直接把产品、产线、设备关系做死在能耗事实里，而应建立独立的生产分母事实层，再与 `energy_consumption_fact_v` 通过时间、区域、产线、设备和分摊规则关联。

首版目标：

- 能算企业/园区级产品产量强度。
- 能算企业/园区级产值强度。
- 能保留后续按产线、区域、设备分摊的接口。
- 能区分“直接计量能源”和“分摊能源”，避免强行制造不存在的产品-设备精确关系。

## 参考依据

- GB/T 2589-2020《综合能耗计算通则》用于综合能耗折标和能源消耗指标计算。
- ISA-95 / IEC 62264 用于企业层 ERP 与制造执行层 MES/MOM 的集成边界和通用术语，生产计划下发、生产绩效上报是核心接口。
- 国家统计局工业总产值口径中，成品价值通常按合格成品实物量乘以不含增值税的产品实际销售平均单价计算；工业总产值还包括对外加工费、自制半成品和在制品期末期初差额。系统首版可先实现“合格产量 × 不含税单价”的主项，字段预留后两项。

## 口径分层

### 1. 单位产品综合能耗

适用场景：

- 单一主产品企业。
- 同一产品或同一可比产品族。
- 产品单位可统一，例如 `t`、`m`、`件`、`kWh`、`m3`。

计算：

```text
单位产品综合能耗 = 综合能耗(tce 或 kgce) / 合格产品标准产量
```

关键约束：

- 分母优先使用合格产量，不使用投料量、计划量、销售量。
- 多产品混产时，不能把不同单位产品直接相加。
- 多产品需要按产品分别计算，或使用等价产量系数折算成“标准产品产量”。

### 2. 单位产值综合能耗

适用场景：

- 多产品混产，物理单位不可直接相加。
- 暂时无法把能源精确分摊到产品。
- 需要评价企业整体能效变化。

计算：

```text
产品产值 = sum(合格产量 * 不含税单价)
单位产值综合能耗 = 综合能耗(tce 或 kgce) / 产品产值(万元)
```

价格口径建议：

- `actual_average_price`：报告期实际销售平均单价，不含增值税。用于对齐统计口径。
- `standard_price`：内部标准单价。用于月度滚动监控，避免价格波动掩盖能效变化。
- `base_period_price`：基期可比价。用于跨年度趋势。

系统默认不要只用销售收入替代产值。销售收入受出货节奏、库存、账期影响；产值应按生产完成口径归属。

### 3. 单位增加值综合能耗

适用场景：

- 对标政府、统计或园区宏观能效要求。
- 企业财务或统计系统能提供工业增加值。

计算：

```text
单位增加值综合能耗 = 综合能耗(tce 或 kgce) / 工业增加值(万元)
```

首版不建议手工反推工业增加值。没有可靠财务数据时，本页只预留字段和接口。

## 数据模型建议

本节模型属于“生产/经营产出分母域”，只服务 `/energy/intensity` 的产品强度、处理量强度、作业量强度和产值强度。它不是产品碳足迹核心模型，不承载 BOM、工序、生命周期边界、活动数据清单或报告结果。

### 产品/产出对象字典

`ProductionProduct`

- `team_id`
- `code`
- `name`
- `spec`
- `category`
- `output_kind`: `product`、`material_storage`、`material_handling`、`operation_workload`
- `default_unit`
- `standard_unit`
- `is_enabled`

`ProductUnitConversion`

- `product_code`
- `from_unit`
- `to_unit`
- `multiply_factor`
- `source`
- `valid_from`
- `valid_to`

`ProductPrice`

- `product_code`
- `price_type`
- `price`
- `currency`
- `tax_included`
- `valid_from`
- `valid_to`
- `source_system`
- `source_record_id`

### 生产分母事实

`ProductionOutputFact`

- 产品/产出对象、产出类型、工单、批次、产线、区域、设备、时间、产出数量、报废量、标准数量、质量状态。
- 只记录已发生的产出事实，不记录计划产量。
- 制造企业可以来自 MES 报工、WMS 成品入库、ERP 完工入库；仓储样本可以来自 WMS 入库、出库、库存或作业流水，但同一批次/源记录不能重复计入。

### 产值事实

首版可以不单独落表，直接由 `ProductionOutputFact.standard_qty * ProductPrice.price` 计算。

后续如果要对齐统计报表，建议新增 `ProductionOutputValueFact`：

- `output_value_current_price`
- `output_value_standard_price`
- `output_value_base_price`
- `processing_fee_value`
- `wip_inventory_delta_value`

### 产品与资源挂接

`ProductionResourceBinding`

- `product_code`
- `work_center_code`
- `line_code`
- `area_id`
- `equipment_id`
- `binding_type`: `primary`、`optional`、`shared`
- `valid_from`
- `valid_to`
- `confidence_level`

这个表只维护“产品/产出对象通常关联哪些资源”，P0 不参与默认强度计算，不能作为能耗精确归因或产品碳足迹分配的唯一依据。

### 与产品碳足迹的边界

产品碳足迹后续单独建模，建议独立包含 `PcfStudy`、`PcfProductModel`、`PcfBatch`、`PcfBoundary`、`PcfActivityFact`、`PcfAllocationRule`、`PcfResult`。当前 `ProductionOutputFact` 只作为产品型号、批次、产量、期间的事实来源之一，不替代产品碳足迹的产品系统、功能单位、生命周期边界和活动数据。

## 能源归因和分摊

### 分摊层级

1. 直接设备计量：能源记录带设备，生产事实也带设备，时间重叠。
2. 产线计量：能源记录带区域/产线，生产事实带产线。
3. 区域计量：能源记录只到区域，按区域内产品产量或机时分摊。
4. 企业公共能耗：办公、照明、空压、空调等公共能耗，按规则分摊或单独保留为“未分摊公共能耗”。

### 分摊规则优先级

| 优先级 | 规则 | 适用场景 |
| --- | --- | --- |
| 1 | 直接设备表计 | 一机一表或设备能源可直接读取 |
| 2 | 设备运行时长 / 机时 | MES/SCADA 有开停机和工单绑定 |
| 3 | 标准能耗系数 | 产品工艺稳定，有标准定额 |
| 4 | 合格产量 | 同产线、同类产品，单位可比 |
| 5 | 产值 | 多产品混产、单位不可比 |
| 6 | 面积或人数 | 公辅系统兜底 |

每条分摊结果必须保存：

- `allocation_rule_id`
- `allocation_basis`
- `allocation_ratio`
- `direct_or_allocated`
- `source_energy_record_id`
- `source_production_record_id`

## 页面设计

在 `/energy/intensity` 后续增加两个业务 Tab：

1. `产品强度`
   - 产品树或产品表。
   - 展示产出数量、标准数量、综合能耗、单位产品/产出对象能耗。
   - 支持产品、产线、区域、设备筛选。

2. `产值强度`
   - 展示产品产值、标准价产值、单位产值综合能耗。
   - 支持当前价、标准价、基期价切换。
   - 多产品混产时优先看这个 Tab。

不要做“口径说明”Tab。需要审计时，用字段级数据表展示来源、价格版本、分摊规则和覆盖率。

## 首版落地建议

P0 不追求产品到设备的精确归因，先做企业/园区级产出分母：

1. 建 `ProductionProduct`、`ProductPrice`、`ProductionOutputFact`。
2. 支持手工导入或 API 接入 MES/WMS 完工产量。
3. `ProductionOutputFact` 至少记录产品/产出对象、产出类型、日期、产出数量、单位、产线/区域可选。
4. `ProductPrice` 支持标准价和实际均价，不含税。
5. `/energy/intensity` 增加产品强度和产值强度汇总。
6. 没有产品-区域-设备挂接时，只展示企业/园区级产品强度，不伪装设备级产品强度。

P1 再做资源挂接和分摊：

1. 维护产品-产线-区域绑定。
2. 支持同一时间窗内的能源与产量关联。
3. 共享能耗通过分摊规则生成 `EnergyProductionAllocationFact`。
4. 页面展示分摊覆盖率和未分摊能耗。

P2 再做高级能力：

1. 接入 MES 工序级报工。
2. 引入标准能耗定额。
3. 按产品、工序、产线、设备做多维对标。
4. 与产品碳足迹页共享产品、BOM、工序和活动数据。

## 验收用例

| 场景 | 预期 |
| --- | --- |
| 单产品企业按月查询 | 返回月综合能耗、合格产量、单位产品综合能耗 |
| 多产品企业按产品查询 | 每个产品单独展示产量和强度，不把不同单位直接相加 |
| 多产品看企业整体 | 使用产值强度，不使用混合物理产量 |
| 缺少价格 | 产值强度为 `null`，产品产量强度仍可计算 |
| 缺少产线绑定 | 不展示产线/设备产品强度，只展示企业级 |
| 有产线绑定但能耗未覆盖 | 展示分摊覆盖率和未分摊能耗 |
| 同一批次 MES 与 WMS 都上报 | 按去重键只计一次 |
