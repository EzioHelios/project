# 微电网智能优化演示模型与数据口径

更新日期：2026-08-14
适用模块：`microgrid` 微电网运行监控、预测、优化与影子调度

## 1. 系统边界

本模块位于第三方 MGCC/PMS 之上。它生成15分钟级计划、目标和运行边界，不承担继电保护、断路器操作、孤岛切换、频率/电压毫秒级控制。当前 `simulation-v1` 适配器仅生成模拟执行回执。

## 2. 数据来源与可信度

| 数据 | 首选来源 | 当前演示处理 | 来源标记 |
| --- | --- | --- | --- |
| 仓库负荷、电量和费用 | 平台 `MeterReadingFact.register_index` 与费率台账 | 按确认绑定投影15分钟功率；历史不足时整段回退确定性曲线 | `measured_projection` / `simulated` |
| 泰州天气 | Open-Meteo 15分钟预报 | 网络不可用时使用确定性泰州夏季曲线 | `forecast` / `simulated` |
| 光伏装机与朝向 | 现场铭牌、设计图 | 祥泰演示V1参数，待现场确认 | `enterprise_assumption` |
| 储能容量、功率与效率 | PCS/BMS铭牌 | 祥泰演示V1参数，待现场确认 | `enterprise_assumption` |
| 充电、照明柔性边界 | 企业生产与安全规则 | 版本化柔性契约 | `enterprise_assumption` |
| 优化计划与回执 | Pyomo/HiGHS、模拟适配器 | 完整保存输入快照和运行版本 | `optimized` / `executed` |

天气服务：

- Open-Meteo Forecast API：<https://open-meteo.com/en/docs>
- Open-Meteo Historical Weather API：<https://open-meteo.com/en/docs/historical-weather-api>
- NASA POWER Hourly API（后续历史辐照交叉校验）：<https://power.larc.nasa.gov/docs/services/api/temporal/hourly/>

祥泰计量绑定只允许管理员预览后确认应用。指定光伏、储能、充电桩和照明电表使用企业提供的精确设备编码，其余设备进入固定负荷；不执行名称模糊匹配。模板同时校验站点和团队，不能用于其他租户。PCC 未确认总表前由已绑定资源能流推导并标记为计算值。

真实历史以最近21天为窗口。覆盖率不低于80%、有效15分钟点不少于864且最新固定负荷不超过30分钟，才可作为预测训练输入；否则整段回退演示历史，不将真实与模拟点拼接。累计表底差分会拒绝复位负差值、重复时间、超过1小时缺口和异常跳变。

## 3. 预测模型

- 负荷预测：`HistGradientBoostingRegressor` 的 P10/P50/P90 分位数模型；历史不足时使用日历基线。
- 光伏预测：pvlib `ModelChain.with_pvwatts`，输入 GHI、DNI、DHI、温度、风速以及版本化容量、倾角、方位角。
- SOC预测：采用物理状态方程，不用机器学习直接猜测SOC。

预测质量门禁分为 `pass`、`warning`、`failed`：点数、有限值、分位数顺序、夜间光伏、天气完整性和物理边界错误为失败；演示回退、基线模型、区间覆盖率低于65%、MAPE高于15%或数据过期为警告。警告只允许用户确认后的风险试算，禁止自动优化和模拟下发；失败禁止优化。

SOC状态方程：

\[
SOC_{t+1}=SOC_t+\frac{\eta_c P^{ch}_t\Delta t-P^{dis}_t\Delta t/\eta_d}{E}
\]

其中 `E` 为可配置额定容量；SOC上下限、充放电效率均来自已发布场景。

## 4. 优化模型

求解器为 Pyomo `appsi_highs`，一期为24小时、15分钟、96时段确定性 MILP。

目标函数纳入：购售电、需量、储能吞吐退化、弃光、备用机燃料/启停和电网碳成本，并允许0–10范围的费用、削峰和减碳业务权重。约束纳入：功率平衡、PCC限额、PV可用功率、储能SOC与充放电互斥、可配置期末SOC目标、充电任务、照明最低服务功率、备用裕度，以及备用机最小功率、启停和爬坡限制。SOC、PCC、设备功率和照明下限始终是硬约束；充电任务可配置为硬约束或带缺额惩罚的软约束。

优化收益与同一输入下的不可调基线比较。基线使用同一负荷、PV、充电总电量、照明服务、分时费率、需量费、碳价、售电价和弃光成本，只关闭储能与柔性时序优化，避免收益口径错配。求解不可行时不允许创建调度批次，并保存约束诊断。

每次优化冻结预测质量、场景版本、完整分时费率、排放因子、碳价、退化成本和策略参数。试算允许使用有明确标记的企业假设；正式优化必须使用已发布场景、通过质量门禁并引用有效费率和排放因子。方案比较只允许同站点、同预测窗口的最多三次运行。费用、峰值或排放变差时以“增加”展示，不将负收益包装为节省。

## 5. 祥泰演示V1企业假设

以下仅用于形成完整演示，不表示现场已确认：PV直流600 kWp/交流500 kW、储能1000 kWh/500 kW、SOC 15%–90%、充电桩群240 kW、照明80 kW且最低服务功率44 kW、PCC 1250 kW。

所有数值存放在版本化场景和设备参数中，来源名称为“祥泰演示V1（待铭牌确认）”，默认置信度0.50。收到现场铭牌、设计图和负荷分类后，应复制场景形成新版本，更新来源与置信度，再重新发布；历史预测和优化运行继续指向原输入快照。

运行监控设备面板使用独立的24小时确定性模拟遥测窗口，仅用于展示SCADA趋势联动。记录统一标记为 `source_kind=simulated`、`quality=D`、`source_ref=xiangtai-demo-v1/scada-telemetry`，初始化时只替换同一来源窗口，不删除或覆盖 `measured` 现场事实。功率轮廓采用分时仓储作业、昼间光伏钟形曲线、充电时窗、照明最低服务功率和储能充放电时段等演示规则；不得用于正式计费、碳核算或现场控制。

## 6. SCADA V3 运行图契约

- 一次系统按“10kV市电 → 高压隔离/断路器 → PCC计量 → 10/0.4kV变压器 → 低压总开关 → 0.4kV母线”建模，PV、储能、充电桩、照明和仓储负荷通过各自的变换与保护设备接入母线。
- 每个节点在场景数据中显式定义 `ports`，包含端口ID、方向、边位、偏移量与电压等级；连线必须精确引用 `sourceHandle` 和 `targetHandle`。场景发布前校验节点、端口与连线引用完整性。
- 前端优先使用母线感知布局：自动识别进线链、母线与出线支路，让支路始终对齐母线端口；非母线图再回退到 Dagre。宽屏为左到右，窄屏为上到下，切换时同步旋转端口边位、应用布局专用偏移量并旋转结构符号，不依赖页面手工坐标。
- 电网、PV、BESS、充电、照明和仓库图标为统一风格的展示资产；隔离开关、断路器、计量、变压器、逆变器和PCS保留可程序化绘制的结构符号，便于与实际状态精确联动。图标不参与电气计算。
