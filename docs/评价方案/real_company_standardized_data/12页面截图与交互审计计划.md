# 四租户 12 页面截图与交互审计计划

更新时间：2026-06-14

## 执行口径

- 每次截图和交互审计必须先选定企业租户，再使用 `enterprises/<enterprise_code>/` 下对应功能目录的数据。
- 截图只证明当前租户、当前页面、当前数据来源状态，不跨企业复用。
- `source_missing`、`partial_source_ready`、`simulation_only` 和业务阻塞项需要单独截图，不允许用演示写入截图替代真实来源。
- 截图前必须确认页面核心区域 loading 已消失；如果持续 loading，记录为 `loading-blocked`，不覆盖已有证据。
- 本计划是补拍和审计计划，不等同于正式操作手册完成版。

## 交互审计初始矩阵

| 页面 | 必须审计的主交互 | 风险动作 | 审计结论字段 |
| --- | --- | --- | --- |
| `/energy/consumption` | Tab 切换、筛选/重置、CSV 上传/粘贴、错误 CSV 下载、消费数据导出 | 上传覆盖或重复导入属于数据写入 | `write_validation_status`、`write_page_visibility_status`、`smoothness_status` |
| `/energy/intensity` | Tab 切换、期间/产品筛选、强度结果刷新 | 无直接写入，重点是来源缺失时的降级体验 | `smoothness_status`、`gap_note` |
| `/energy/analysis` | Tab 切换、查询/重置、图表加载 | 无直接写入，重点是空态是否清楚 | `smoothness_status`、`gap_note` |
| `/energy/benchmark` | 新增档案、新增对标项、筛选、记录回显 | 删除/停用对标项属于破坏性或状态变更 | `write_validation_status`、`risk_note` |
| `/energy/flow` | Tab 切换、查询、能流图加载、损耗诊断切换 | 无直接写入，重点是缺计量层级时不误判 | `smoothness_status`、`gap_note` |
| `/energy/balance` | 优化测算、保存优化记录、记录回显 | 保存模拟结果不能覆盖真实来源判断 | `write_validation_status`、`source_status` |
| `/energy/budget` | 新增预算目标、生成月度预算、新增调整、刷新 | 预算调整和审批属于业务状态写入 | `write_validation_status`、`risk_note` |
| `/carbon/accounting` | 生成设施、发布边界、重建清单、下载缺结果、锁定批次 | 发布边界和锁定批次为高影响状态变更 | `write_validation_status`、`blocked_reason` |
| `/carbon/product-footprint` | 新建研究、边界、阶段、清单、结果、报告导出 | 报告导出需区分企业来源和验证写入 | `write_validation_status`、`export_status` |
| `/carbon/supply-chain` | 新建供应商/场站/任务/数据/证据、审核、披露 | 披露/发布可能触达外部协作对象 | `write_validation_status`、`risk_note` |
| `/carbon/verification` | 创建项目、登记附件、生成材料包、下载 ZIP | 大文件下载、材料包生成和报告导出需记录任务状态 | `write_validation_status`、`export_status` |
| `/carbon/assets` | 新建履约周期、账户、配额、信用、交易、清缴、预测情景 | 配额、交易、清缴若接真实台账属于高风险写入；当前仅模拟 | `write_validation_status`、`simulation_status` |

## 回填要求

每个企业/页面组合完成后，至少回填：

| 字段 | 说明 |
| --- | --- |
| `source_status` | `ready_for_platform_validation`、`partial_source_ready`、`source_missing_or_assumption_only`、`simulation_only` |
| `smoothness_status` | 页面实际操作是否流畅，是否出现加载、错误、下载失败、入口难找 |
| `write_validation_status` | 写入闭环、导入覆盖、部分来源覆盖、源缺失阻塞或缺计算结果阻塞 |
| `evidence_marker` | 对应 `SHOT-*` 截图编号或运行验证文件 |
| `gap_note` | 缺数据、缺页面入口、缺业务规则、性能或体验问题 |
