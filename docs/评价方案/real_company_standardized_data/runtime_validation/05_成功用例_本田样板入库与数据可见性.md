# 成功用例：本田样板租户入库与 12 页面数据可见性

测试时间：2026-06-14

测试对象：

- 企业：本田金属技术(佛山)有限公司
- 租户：`fs-honda-metal-2025`
- 数据包：`docs/评价方案/real_company_standardized_data/enterprises/honda`

## 功能概述

从真实企业核查资料包生成的标准化数据，正式导入为独立租户数据，并验证 12 个能碳功能页面的数据库基础数据是否存在，以及辅助核查材料包能否带出原始证据文件。

本用例验证“数据能否进入平台并具备页面读取基础”和“材料包导出是否能包含原始证据文件”，不替代浏览器逐项点击、筛选、导出和报告下载验收。

## 操作步骤

1. 执行正式导入：

```bash
./.venv/bin/app carbon import-real-company-package docs/评价方案/real_company_standardized_data/enterprises/honda
```

2. 执行页面数据可见性验证：

```bash
./.venv/bin/python tools/validate_real_company_tenant_visibility.py --tenant-slug fs-honda-metal-2025 --enterprise-code honda
```

3. 调用平台导出用例创建核查材料包导出任务，使用本田租户上下文和样板清单批次。

4. 检查输出文件：

```text
docs/评价方案/real_company_standardized_data/runtime_validation/fs-honda-metal-2025_page_data_visibility.csv
docs/评价方案/real_company_standardized_data/runtime_validation/fs-honda-metal-2025_page_data_visibility.md
```
