# SC-四租户核查证据包导出

测试时间：2026-06-14

## 功能概述

验证每个企业资料包作为独立租户进入平台后，辅助核查模块能否生成 `material_package` 材料包，并把报告文件、manifest、审计清单和原始证据文件一起下载为 ZIP。

## 操作步骤

1. 使用 `app carbon import-real-company-package docs/评价方案/real_company_standardized_data/enterprises` 将四个企业子包分别导入独立租户。
2. 执行 `node tools/validate_verification_evidence_packages_with_playwright.mjs`。
3. 脚本逐租户登录，设置 `x-team-id`，创建 `/api/carbon/verification/export-jobs` 的 `material_package` 任务。
4. 通过下载接口流式保存 ZIP 到 `runtime_validation/verification_evidence_exports/<tenant_slug>/`。
5. 检查 ZIP 条目、`manifest.json`、`evidence/evidence-manifest.csv`、报告文件和证据原件纳入状态。

## 验证点

- 四个企业资料包没有跨租户混用数据。
- `source_files.csv`、Scope1/Scope2/Scope3 台账附件均归档到仓库内 `evidence_archive/<enterprise_code>/`。
- Maibo 嵌套压缩包内的证据成员可在导入时解包并进入材料包。
- 大 ZIP 下载使用 Node 流式写文件，避免浏览器/Node 内存拷贝导致 OOM。
