## 操作路径

- 登录实施管理员账号。
- 切换到对应企业租户。
- 打开 `/energy/consumption?tab=import`。
- 在“企业资料包导入”中选择单个企业资料包。
- 点击“试运行”，检查整包导入结果区和后端返回的导入计数。
