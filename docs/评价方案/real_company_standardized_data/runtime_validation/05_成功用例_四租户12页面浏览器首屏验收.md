# 成功用例：四租户 12 页面浏览器首屏验收

测试时间：2026-06-14

测试对象：

- 本田金属技术(佛山)有限公司：`fs-honda-metal-2025`
- 鸿通科技（厦门）有限公司：`xm-hongtong-2025`
- 宁波迈柏科技股份有限公司：`nb-maibo-2025`
- 上海马陆日用友捷汽车电气有限公司：`sh-malu-youjie-2025`

## 功能概述

使用真实企业资料包正式入库后的独立租户，从浏览器访问 12 个能碳功能页面，验证页面首屏可访问、租户上下文可设置、主要 API 不返回 4xx/5xx、页面无明显运行时错误。

本用例不替代上传、录入、筛选、导出、材料包下载等深度操作验收，因此总矩阵中的 `smoothness_status` 记录为 `partial`。

## 操作步骤

1. 正式导入四个企业资料包：

```bash
./.venv/bin/app carbon import-real-company-package docs/评价方案/real_company_standardized_data/enterprises
```

2. 确认测试账号存在：

```bash
./.venv/bin/app users seed-admin
```

3. 对每个租户运行浏览器首屏验收脚本：

```bash
node tools/validate_real_company_pages_with_playwright.mjs --enterpriseCode honda --tenantSlug fs-honda-metal-2025 --teamId 564728a0-8ecd-4a8b-a5de-1e2bf6c8073e --teamName '本田金属技术(佛山)有限公司'
node tools/validate_real_company_pages_with_playwright.mjs --enterpriseCode hongtong --tenantSlug xm-hongtong-2025 --teamId 813d946c-8fa0-4b49-884d-cdf2efeeb205 --teamName '鸿通科技（厦门）有限公司'
node tools/validate_real_company_pages_with_playwright.mjs --enterpriseCode maibo --tenantSlug nb-maibo-2025 --teamId f3d9cac2-ecc4-4bb4-b819-478c666b7914 --teamName '宁波迈柏科技股份有限公司'
node tools/validate_real_company_pages_with_playwright.mjs --enterpriseCode malu --tenantSlug sh-malu-youjie-2025 --teamId 4b9eab67-044d-4671-830d-570fcbc427d9 --teamName '上海马陆日用友捷汽车电气有限公司'
```

4. 检查输出文件：

```text
runtime_validation/fs-honda-metal-2025_browser_page_validation.csv
runtime_validation/xm-hongtong-2025_browser_page_validation.csv
runtime_validation/nb-maibo-2025_browser_page_validation.csv
runtime_validation/sh-malu-youjie-2025_browser_page_validation.csv
```
