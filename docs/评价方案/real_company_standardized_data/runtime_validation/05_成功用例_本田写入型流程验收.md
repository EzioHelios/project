## 业务前置条件记录

本田资料包原始组织边界为 `draft`，且缺少纳入设施。平台后端要求只能基于已发布组织边界创建碳核算批次，发布边界前还必须至少有一个纳入设施。

本次验收通过平台接口补齐了一个“资料包验收设施”，发布边界后再创建核算批次。这个流程证明平台可以继续走通，但也说明真实企业资料包导入时需要把边界设施作为必备前置数据，或在页面上提供清晰的边界发布引导。
