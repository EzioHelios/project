# SC-四租户辅助核查页面导出下载

测试时间：2026-06-14

## 功能概述

验证企业用户在辅助核查页面中，能否通过页面控件生成核查材料包，并从导出记录中下载 ZIP。该用例补充验证 UI 操作路径，不替代接口级证据完整性验证。

## 操作步骤

1. 登录平台并设置当前企业租户。
2. 进入 `/carbon/verification` 辅助核查页面。
3. 切换到“报告导出”页签。
4. 点击“生成核查材料包”。
5. 等待导出记录出现新任务且状态为 `completed`。
6. 点击该任务行“下载”。
7. 保存 ZIP 并检查 `manifest.json` 与 `evidence/evidence-manifest.csv`。

## 验证点

- 页面级生成按钮可触发材料包导出任务。
- 导出记录中可看到新任务并提供下载入口。
- 浏览器下载事件可捕获，ZIP 文件可保存到本地验证目录。
- 下载 ZIP 包含 manifest 和证据 manifest。
