# SC-四租户 12 页面非破坏性深测

测试时间：2026-06-14

## 功能概述

验证四个真实企业租户进入平台后，12 项能碳功能页面是否能完成非破坏性用户操作：页面访问、Tab 切换、查询/重置/刷新、安全打开新增入口、页面数据提示检查。

## 操作步骤

1. 使用管理员账号登录平台。
2. 设置当前租户为待测企业。
3. 逐个访问 12 个页面。
4. 依次切换页面主要 Tab。
5. 点击查询、重置、刷新等不会改变业务状态的按钮。
6. 对存在新增入口的页面，只打开入口并关闭，不提交数据。
7. 记录 API 失败、页面错误、控制台 warning/error 计数和页面数据提示。
