# 四租户 12 页面真实资料包验收操作手册

更新时间：2026-06-14

## 适用范围

本手册用于真实企业资料包进入平台后的页面验收和后续操作记录。每次验收必须先选定一个企业租户，再使用该企业 `enterprises/<enterprise_code>/` 子目录下对应功能目录的数据，不跨企业补数据。

当前四个租户：

| 企业 | 租户 | 企业子包 |
| --- | --- | --- |
| 本田金属技术(佛山)有限公司 | `fs-honda-metal-2025` | `enterprises/honda/` |
| 鸿通科技（厦门）有限公司 | `xm-hongtong-2025` | `enterprises/hongtong/` |
| 上海马陆日用友捷汽车电气有限公司 | `sh-malu-youjie-2025` | `enterprises/malu/` |
| 宁波迈柏科技股份有限公司 | `nb-maibo-2025` | `enterprises/maibo/` |

验收前置动作：

1. 登录平台并切换到待验收企业租户。
2. 对照该企业 `page_upload_validation_checklist.csv` 确认页面、路由、数据目录和缺失数据集。
3. 如需重新导入固定标准化企业子包，进入 `/energy/consumption` 的“数据导入”Tab，先在“企业资料包导入”区块选择企业并执行试运行，确认结果区显示目标企业、入库计数和来源缺口页面，再由实施/验收管理员正式导入。四企业试运行路径已验证，证据见 `runtime_validation/real_company_package_import_playwright_validation.md`。
4. 先看页面的来源状态，再做上传、录入、计算、导出或下载操作。
5. 对 `source_missing`、`partial`、`simulation_only`、`blocked_*` 单独记录，不补造为真实企业数据。
6. 每次验收结果回填总矩阵或运行验证文件，保留操作路径、成功信号和阻塞原因。

## 12 页面主流程

### M-001 能源消费 `/energy/consumption`

前置数据目录：`05_energy_management/`，重点数据集为 `energy_interval_facts`、`scope1_stationary_combustion`、`scope2_electricity_bills`。

操作步骤：

1. 打开 `/energy/consumption`。
2. 查看“来源状态”，确认能源事实、Scope1 固定燃烧、Scope2 电力账单是否为真实来源、部分来源或来源缺失。
3. 如需企业用户导入，进入“数据导入”Tab，选择对应数据集并上传或粘贴标准 CSV。
4. 查看导入结果的接收行、入库行、跳过行和逐行错误；有错误时下载错误 CSV。
5. 回到消费视图，检查列表、统计、筛选和明细是否显示该租户数据。

通过判定：真实来源行存在，导入成功行可在页面/API 可见；错误行可下载并保留原始行。

阻塞判定：企业子包缺少能源事实或 Scope 数据时记录 `source_missing`，不能用演示写入代替真实能源消费结论。

### M-002 能源强度 `/energy/intensity`

前置数据目录：`05_energy_management/`，重点数据集为 `energy_interval_facts`、`production_output_facts`、`production_products`。

操作步骤：

1. 打开 `/energy/intensity`。
2. 查看“来源状态”，确认能源事实和产量分母是否同时存在。
3. 对本田、鸿通、迈柏这类能源事实和产量分母齐备的租户，检查单位产品能耗或能源强度是否能按期间、产品维度计算。
4. 对马陆这类缺产量分母的租户，记录缺失数据集和部分来源状态。

通过判定：能源事实和产量分母均存在时，可计入真实来源驱动的分析页面。

阻塞判定：只有产品主数据或只有部分能源来源时，记录 `partial_source_ready`，不能计入真实完整录入。

### M-003 能源分析 `/energy/analysis`

前置数据目录：`05_energy_management/`，重点数据集为 `energy_interval_facts`。

操作步骤：

1. 打开 `/energy/analysis`。
2. 查看“来源状态”，确认能源事实是否存在。
3. 检查月度趋势、能源结构、区域或设备维度分析是否由真实能源事实驱动。
4. 对缺少 `energy_interval_facts` 的企业，记录空态和下一步数据准备动作。

通过判定：真实能源事实存在并驱动图表或分析结果。

阻塞判定：缺能源事实时只记录 `source_missing`，不以空图或演示数据通过。

### M-004 能效对标 `/energy/benchmark`

前置数据目录：`05_energy_management/`，重点数据集为 `energy_interval_facts`、`production_output_facts`。

操作步骤：

1. 打开 `/energy/benchmark`。
2. 查看“来源状态”，确认能源事实和产量分母准备情况。
3. 创建或复用对标档案、对标项，检查页面是否能回显验证记录。
4. 若企业缺产量或能源来源，只把该写入记为页面流程验证。

通过判定：来源完整时，对标数据能与能源/产量数据对应。

阻塞判定：源缺失时即使可创建对标对象，也不能作为真实能效对标结论。

### M-005 能流图 `/energy/flow`

前置数据目录：`05_energy_management/`，重点数据集为 `energy_interval_facts`。

操作步骤：

1. 打开 `/energy/flow`。
2. 查看“来源状态”，确认能流图所需能源事实是否存在。
3. 检查节点、边、能源流量是否由当前租户能源事实生成。
4. 对缺少完整计量层级的企业，记录降级显示或空态。

通过判定：真实能源事实可驱动能流节点和边。

阻塞判定：缺能源事实时记录 `source_missing`。

### M-006 能量平衡 `/energy/balance`

前置数据目录：`05_energy_management/`，重点数据集为 `energy_interval_facts`。

操作步骤：

1. 打开 `/energy/balance`。
2. 查看“来源状态”，确认平衡计算是否有真实能源事实支撑。
3. 创建或复用能量平衡模拟、平衡记录，检查输入、转换、输出和损失项是否可校验。
4. 对无真实能源事实租户，将该动作记录为模拟/写入流程验证。

通过判定：真实能源事实存在且平衡结果可追溯。

阻塞判定：源缺失租户的平衡写入不计入真实完整录入。

### M-007 能源预算 `/energy/budget`

前置数据目录：`05_energy_management/`，重点数据集为 `energy_interval_facts`、`production_output_facts`。

操作步骤：

1. 打开 `/energy/budget`。
2. 查看“来源状态”，确认预算基线所需能源事实和产量分母。
3. 创建预算计划、分配或调整记录，检查预算、实际值、偏差是否可展示。
4. 对缺源企业，保留来源缺失或部分来源标记。

通过判定：历史能源和产量来源完整时，可形成真实预算基线。

阻塞判定：源缺失时预算写入只能证明页面可操作。

### M-008 碳核算 `/carbon/accounting`

前置数据目录：`01_carbon_accounting/`，重点数据集为 `reporting_organizations`、`reporting_periods`、`organization_boundaries`、Scope1/Scope2/Scope3 活动数据、核算批次和清单。

操作步骤：

1. 打开 `/carbon/accounting`。
2. 进入“组织边界”，检查是否已有纳入设施；没有设施时使用“生成设施”，再发布边界。
3. 进入“核算结果”，查看“来源状态”，确认边界、Scope 活动数据、纳入清单和最近批次状态。
4. 执行清单重建，检查纳入记录数、缺结果记录和计算结果。
5. 只有清单非空且无缺计算结果时，才允许锁定批次。
6. 对本田，确认 3 条固废 Scope3 记录已使用企业清册“排放因子-废料”sheet 的可追溯 ecoinvent 因子完成计算；如后续企业出现缺结果批次，再使用缺结果清单、补录模板和补录 CSV 校验链路处理。
7. 对鸿通、马陆、迈柏，记录组织层 Scope 来源仍不完整；迈柏当前已有 Scope2 电力来源，可重建 12 条纳入清单并锁定，但不能认定为完整组织 GHG 盘查。

通过判定：四租户均可发布边界、重建清单并锁定；其中本田可计入完整组织碳核算闭环，鸿通、马陆、迈柏因组织层 Scope 来源不完整记为部分来源。

阻塞判定：清单为空或缺可验证 CO2e 结果时不得锁定；组织 Scope 来源不完整时即使可锁定，也不能计入完整组织 GHG 盘查。

### M-009 产品碳足迹 `/carbon/product-footprint`

前置数据目录：`02_carbon_product_footprint/`，重点数据集为 `product_footprint_studies`、`product_system_boundaries`、`product_lifecycle_stages`、`product_footprint_inventory_items`、`product_footprint_results`。

操作步骤：

1. 打开 `/carbon/product-footprint`。
2. 查看“来源状态”，确认企业资料包来源记录和验证写入记录分开统计。
3. 检查产品研究、系统边界、生命周期阶段、活动清单和结果是否可见。
4. 进入“报告生成”，选择或确认 `PCF-*` 企业包研究，点击“导出报告”。
5. 下载 ZIP 后检查 `product-footprint-report.docx`、`report-context.json`、`inventory-items.csv`、阶段汇总、质量摘要和 `manifest.json`。

通过判定：四租户均显示 `真实来源`，核心 PCF 记录存在，公共报告 ZIP 可下载且 manifest 与当前企业研究匹配。

阻塞判定：验证写入记录只能证明页面可写，不能替代企业资料包来源。

### M-010 供应链碳管理 `/carbon/supply-chain`

前置数据目录：`03_carbon_supply_chain/`，重点数据集为 `supply_chain_suppliers`、`supplier_sites`、`supplier_disclosure_tasks`、`supplier_carbon_data`、`source_files`。

操作步骤：

1. 打开 `/carbon/supply-chain`。
2. 查看“来源状态”，确认企业资料包来源记录和验证写入记录分开统计。
3. 检查供应商、场站、填报任务、碳数据和证据是否可见。
4. 创建或复用供应商、任务、数据、证据、审核和披露记录。

通过判定：四租户均显示 `真实来源`，供应商 PCF 数据和证据链可追溯。

阻塞判定：供应商 PCF 不应自动混入组织 Scope3，除非有明确发布规则。

### M-011 辅助核查 `/carbon/verification`

前置数据目录：`04_carbon_verification/`，重点数据集为 `carbon_verification_projects`、核算批次、清单、产品碳足迹清单和 `source_files`。

操作步骤：

1. 打开 `/carbon/verification`。
2. 查看“来源状态”，确认企业来源记录、就绪附件、材料包文件、缺失凭证和平台生成记录。
3. 进入“凭证清单”，检查附件路径、SHA256、状态和缺失凭证。
4. 进入“核查材料包”，检查材料组和 manifest 文件。
5. 进入“报告导出”，点击“生成核查材料包”，在导出记录中下载 ZIP。
6. 检查 ZIP 中 `manifest.json`、`evidence/evidence-manifest.csv`、报告文件、审计 CSV 和原始证据文件。

通过判定：四租户均显示 `真实来源`；335/335 个证据项进入 ZIP，`missing_file=0`；页面级导出下载 4/4 通过。

阻塞判定：平台生成记录只能证明报告和导出流程，不能替代企业原始证据来源。

### M-012 碳资产 `/carbon/assets`

前置数据目录：`06_carbon_assets/`，当前仅有 `carbon_assets_assumptions` 和核算批次作为模拟种子。

操作步骤：

1. 打开 `/carbon/assets`。
2. 查看“资产来源”，确认当前企业包是否只有模拟来源。
3. 创建或复用履约周期、账户、配额、信用、交易模拟、清缴和预测情景。
4. 检查页面是否明确显示可追溯资产台账为 0、模拟种子存在。

通过判定：四租户均显示 `模拟来源`，页面可操作但不计入真实碳资产台账完成。

阻塞判定：未补充真实配额、CCER、交易或清缴来源前，不进入真实碳交易辅助决策验收。

## 记录口径

每页验收至少记录：

- 租户和企业子包。
- 页面路由和功能目录。
- 来源状态与缺失数据集。
- 实际操作动作。
- 成功信号或阻塞原因。
- 运行验证文件或截图编号。

推荐状态值：

| 状态 | 含义 |
| --- | --- |
| `source_readiness_passed` | 来源状态面板/API 已验证 |
| `write_flow_passed` | 页面/API 写入闭环通过 |
| `source_import_visible_not_page_write` | 真实资料包导入后可见，但页面无直接录入入口 |
| `partial_source_import_not_page_write` | 部分来源可见，不能计入完整录入 |
| `source_missing_not_validated` | 源数据缺失，不做端到端录入通过；当前四租户总矩阵为 0 |
| `write_flow_blocked_source_missing` | 平台正确阻断源缺失业务；当前四租户总矩阵为 0 |
| `write_flow_blocked_missing_result` | 平台正确阻断缺计算结果业务；当前四租户总矩阵为 0 |
| `simulation_only` | 仅模拟或假设数据 |
