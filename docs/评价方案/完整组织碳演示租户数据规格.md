# 完整能碳演示租户数据规格

## 1. 用途与边界

本规格定义独立租户“华东综合能源示范园区”的可重复演示数据。数据规模参考既有仓储园区项目，但不读取、复制或覆盖任何客户租户数据，不包含客户名称、设备编号、合同编号或原始凭证。

演示期间固定为：

- 2024年1月1日至12月31日：完整基准年，已锁定、已发布、已完成核查；
- 2025年1月1日至12月31日：完整对比年，包含报告退回、修订和发布记录；
- 2026年1月1日至8月31日：年内累计期间，保留月结复核和核查待办状态，不表达为完整年度。

## 2. 标准与数据来源

组织边界、报告期间、分类与核查流程分别依据：

- ISO 14064-1:2018；
- GHG Protocol Corporate Standard；
- ISO 14064-3:2019；
- 平台已发布的组织温室气体报告配置与计算方法版本。

排放因子分为两类：

1. 权威来源冻结值：外购电力、燃料燃烧和制冷剂GWP，记录来源名称、版本、参考年度、地域、质量等级和不确定性；
2. 企业批准的演示假设：运输、包装材料、废弃物、租赁资产和云服务等活动，明确标记为企业演示假设，不宣称为监管默认因子。

## 3. 资源颗粒度

数据包含园区、设施、运营区域三级共10个区域，以及关口电表、光伏、储能、变压器、锅炉、发电机、制冷、输送、立库、照明、暖通、空压机、充电桩、叉车和固废称重等19类代表性设备。

每条排放活动必须完成100%区域归集；外购电力按自动化仓、冷链仓、分拣、办公、动力和充电区域分配，并保留设备快照。价值链活动保留外部设施标识，但不伪造外部设备。

微电网站点使用同一套区域和设备主数据，包含PCC、光伏、储能、充电桩、照明和仓储作业负荷六类资源，以及11条设备计量绑定。固定负荷预测使用安装时点之前连续21天、15分钟粒度的可重复计量投影，预测、优化和模拟调度继续调用正式领域用例，不另写旁路结果。组织盘查期间固定，运行监控窗口随安装时点刷新，以保证数据就绪状态和调度回执可直接演示。

## 4. 功能覆盖

确定性生成器必须覆盖：

- Scope 1、Scope 2、Scope 3；
- ISO 14064-1六个排放类别；
- 2024、2025完整12个月及2026年1—8月；
- 组织边界、活动台账、独立参数、计算运行、证据、报告版本与审批；
- 组织碳核查项目、发现项和报告模板；
- 减排目标、项目、边界、基准线、监测计划、计算、财务、复核、CCER材料台账；
- SBTi、CDP、RE100目标、披露、可再生电力主张和评估；
- 企业年度能碳预算及月度分解。
- CEA、CCER、绿证主数据，资产账户、批次、变动、唯一使用、企业自愿抵消计划及成本情景；
- 微电网一次系统、设备状态、计量绑定、96点负荷/PV/SOC预测、Pyomo + HiGHS MILP优化；
- 通过预测质量门禁的正式优化、288条模拟调度指令和执行回执。

安装命令：

```bash
app demo install-showcase --profile transition
app demo verify-showcase
```

安装器为幂等操作，只管理 `DEMO-PARK` 前缀、`demo-industrial-park` 微电网站点及本规格来源标记的数据。覆盖率验证失败时不得将该租户作为正式演示环境交付。

## 5. 碳资产边界

- 全国碳排放配额（CEA）作为制度、品种和价格参考；园区不是全国碳市场法定重点排放单位，因此不生成配额持仓。
- 国家核证自愿减排量（CCER）只建立外部采购批次和注销记录，不与园区普通屋顶光伏或内部减排项目建立签发关系。
- 绿证使用量与RE100可再生电力声明一一关联，并保存批次、用途、期间和证据索引。
- 企业自愿抵消计划与法定履约义务分开命名和记录，不回写组织温室气体盘查结果。
- 市场行情使用上海环交所、全国自愿减排交易系统和国家能源局的官方公开观测值；企业预算价和压力价只进入成本情景。
