# 组织碳后续能力待分析清单

本阶段仅交付组织温室气体盘查基础闭环：组织边界、活动数据、核算运行、结果分析、证据追溯和内部盘查报告。以下能力不纳入本阶段代码范围，后续应分别形成标准研究、领域模型和验收方案后再实施。

## 第三方核查

- 核查机构、核查组、独立性声明与资质档案。
- 风险分析、抽样计划、现场核查、问题清单和整改关闭。
- 保证等级、实质性阈值、核查意见与声明签发。
- 与 ISO 14064-3、认可规范及行业核查指南的逐条对应。

现有“核查支撑”页面保持原状，不作为本次组织碳盘查闭环的验收依据。

## 温室气体减排

- 基准情景、项目边界、额外性、泄漏和监测计划。
- 方法学版本、参数、减排量计算、核证与签发记录。
- 项目级减排与组织盘查减排的口径隔离和勾稽关系。

在完成适用方法学研究前，不从组织盘查结果自动推导“核证减排量”。

## 目标与预算

- 基准年重算政策、目标边界、绝对/强度目标和范围覆盖。
- 年度预算分解、滚动预测、偏差分析与责任归集。
- 可再生能源证书、碳信用和抵消的使用顺序与披露。

本轮 48–51 专项仅按同一筛选时间、区域或设备只读展示已配置碳预算，实际排放仍只取组织碳核算结果；缺少完整月度预算时不生成推算目标。目标版本、基准年重算、审批和正式数据接口仍作为后续独立能力设计。
