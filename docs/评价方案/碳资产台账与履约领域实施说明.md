# 碳资产台账与履约领域实施说明

## 1. 适用范围

本说明约束平台中的配额、国家核证自愿减排量、绿色电力证书、履约结算、市场行情与碳成本测算。系统提供企业内部台账、情景分析和履约准备，不替代注册登记机构、交易机构或主管部门的正式记录。

## 2. 资产分类与单位

| 工具类别 | 平台编码 | 原生单位 | 可进入碳履约 | 主要业务用途 |
|---|---|---|---|---|
| 全国碳排放配额 | `CEA` | `tCO2e` | 是 | 配额持有、交易、清缴 |
| 国家核证自愿减排量 | `CCER` | `tCO2e` | 按规则版本限定 | 抵销、交易、项目签发衔接 |
| 绿色电力证书 | `GREEN_CERTIFICATE` | `certificate` | 否 | 可再生能源电力消费与环境属性声明 |

三个类别不换算后合并余额。绿证使用记录不得进入配额清缴或 CCER 抵销结算。

## 4. 数据和计算规则

1. `CarbonAssetInstrument` 固定类别、原生单位、市场与登记机构。
2. `CarbonAssetLot` 保存配额分配、CCER签发、绿证核发或采购形成的可追溯批次。
3. `CarbonAssetMovement` 是追加式已入账流水。已入账流水不可修改或删除，差错通过等额反向流水更正。
4. 批次可用余额等于批次取得数量与全部已入账变动的代数和，任何业务不得使余额小于零。
5. 履约义务使用主管部门口径的覆盖排放量或应清缴量，不直接引用完整组织温室气体盘查总量。
6. CCER最大抵销比例、适用工具与有效期存入 `CarbonComplianceRuleVersion`；每次履约结算冻结规则快照。
7. 绿证使用写入 `EnvironmentalAssetUsage`，用途限于可再生电力声明等非碳履约场景。
8. `CarbonMarketQuote` 只接受 `observed` 或 `imported` 数据。系统不得从单个价格点生成历史行情。
9. 成本测算运行冻结履约义务、资产余额、规则版本、价格和情景参数；历史运行不受后续配置修改影响。

## 5. 数据来源字段

正式台账至少保留资产编号、登记账户、批次或序列号、业务日期、数量、原生单位、来源名称、标准/规则版本和证据引用。行情至少保留交易日、价格、报价单位、来源名称、来源版本和来源链接。

缺少正式来源的数据不得以“市场历史”“正式持仓”或“已履约”状态入账。成本测算允许使用用户明确录入的情景价格，但情景结果与市场行情台账保持独立。

## 6. 产品工作台

| 页面 | 核心职责 |
|---|---|
| 资产总览 | 汇总分类余额、市场估值、履约覆盖与最近流水 |
| 资产台账 | 建立工具对应账户，登记可追溯批次，追加业务流水并保留来源与凭证引用 |
| 履约管理 | 选择规则版本，登记履约义务，计算CEA/CCER覆盖与缺口，形成并提交批次级结算 |
| 成本测算 | 由用户录入价格和安全裕度，冻结义务、余额、规则与测算结果 |
| 市场行情 | 维护可追溯的观测或导入行情，不生成合成历史 |
| 绿证权益 | 管理绿证批次及其在可再生电力声明等非碳履约场景中的使用记录 |
