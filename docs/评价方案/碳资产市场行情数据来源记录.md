# 碳资产市场行情数据来源记录

更新日期：2026-08-23

## 1. 数据边界

市场行情只保存有公开发布主体、发布日期、数值口径和原文地址的观测数据。不生成历史行情，不用预算价插值成价格曲线，也不在采集失败时写入“兜底行情”。

企业预算价、压力测试价和采购安全边际只保存在 `CarbonCostScenario`，用于费用测算，不写入 `CarbonMarketQuote`。

## 2. 固定公开来源

| 品种 | 公开发布主体 | 采用指标 | 频率 | 官方入口 |
| --- | --- | --- | --- | --- |
| 全国碳排放配额（CEA） | 上海环境能源交易所 | 挂牌协议交易收盘价；开高低收；全市场当日成交量和成交额 | 交易日 | https://overview.cneeex.com/qgtpfqjy/mrgk/2026n/ |
| 国家核证自愿减排量（CCER） | 全国温室气体自愿减排交易系统 | 能源产业日成交均价、成交量和成交额 | 交易日 | https://www.ccer.com.cn/wcm/ccer/html/2502sjcx/index.html |
| 可再生能源绿色电力证书 | 国家能源局 | 全国绿证单独交易的分电量生产年份成交量与平均价格 | 月度 | https://www.nea.gov.cn/ |

绿证价格必须与电量生产年份一起使用。演示租户的绿证批次属于2025年电量，因此市场页使用国家能源局公布的2025年电量绿证月度均价，不使用跨年份综合均价。

## 3. 演示包公开快照

`src/py/app/demo/showcase/market_data.py` 保存可重复安装的官方快照：

- CEA：2026年1—8月的8个月末或最新交易日；
- CCER：2026年1—8月的8个月末或最新交易日；
- 绿证：国家能源局已发布的2026年1—6月、2025年电量绿证月度均价，共6个观测点。

每条快照保存 `trade_date`、`published_at`、`source_name`、`source_version`、`source_url` 和官方成交量。绿证月度通报未公布该年份成交额，因此不用“均价×成交量”伪造官方成交额。

## 4. 指标映射

`CarbonMarketQuote.close_price` 存放该来源的主价格指标，其业务含义由 `source_version` 锁定：

| `source_version` | 页面口径 |
| --- | --- |
| `daily-close-v1` | 日收盘价 |
| `daily-average-v1` | 日成交均价 |
| `monthly-average-vintage-2025-v1` | 月度均价（2025年电量） |
| `manual-observed-v1` | 经办人登记的已观测价格 |

页面统一使用“价格”作为列名，另列展示“价格口径”，避免将CCER和绿证均价错称为收盘价。

## 5. 同步与失败规则

1. 生产环境后续通过定时任务按官方公开频率同步，入库前校验发布日、指标口径、单位和原文地址。
2. 来源无法访问或页面解析失败时，保留最后一条已验证观测值和数据新鲜度状态，不新增估算行情。
3. 任何人工登记必须保留来源名称；正式同步还必须保留原文URL和发布时间。
4. 国家能源局2026年7月已发布中国绿证价格指数；该指数是相对指数，不当作“元/个”价格写入现有行情表。如需展示，应增建独立指数时序。
