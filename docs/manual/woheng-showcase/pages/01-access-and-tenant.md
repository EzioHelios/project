# 登录、首页与租户切换

## 登录平台

使用演示账号进入平台。登录完成后，系统进入首页或上次访问页面。演示前应确认当前账号具备能碳管理、数据维护、核查支撑和系统审计相关权限。

## 首页工作台

首页用于确认当前租户和主要功能入口。演示时先介绍左侧导航和首页入口，再说明平台能力围绕能源运营、碳数据填报、组织碳核算、监测告警、态势展示和报告材料展开。

## 切换生产基地

在租户切换入口选择「沃衡汽车泰州生产基地」或「沃衡汽车湖州生产基地」。切换后，页面数据、设备、区域、经营台账、核算结果和报告记录会按照租户隔离展示。

演示租户切换时建议先打开首页，再切换到另一个基地，随后进入设备或组织碳页面说明数据差异。泰州侧重设备接入和监测告警，湖州侧重经营活动、组织碳和报告导出。

## 检查项

1. 页面显示沃衡汽车能碳管理平台品牌。
2. 当前租户名称与演示口径一致。
3. 首页入口与绿色工厂评价十二类功能保持对应。
4. 切换租户后业务数据、设备和报告记录发生对应变化。
