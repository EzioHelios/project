# 态势大屏

从侧边栏「态势大屏」进入总览、电量监控和能碳协同页面。切换生产基地后，大屏显示当前租户的数据。

## 态势总览

进入 `/bigscreen/overview`，查看当前基地的能耗、碳排和区域运行信息。切换租户后，核对大屏显示的基地名称和业务数据。

{{evidence:EV-WH-003}}

## 电量监控

进入 `/bigscreen/power`，查看电量指标、区域电量和用电趋势。需要核对表计配置及采集记录时，返回「设备与测点 / 电表电量」。

{{evidence:EV-WH-005}}

## 能碳协同

进入 `/bigscreen/carbon`，查看组织碳排放结果及其结构。需要核对活动数据、因子或核算运行时，进入「碳核算」对应页面。

{{evidence:EV-WH-004}}
