# 能效对标分析

本章说明如何查看基地、区域、用能系统、设备、产线和产品的能效对标结果。对标分析页用于集中展示实际值、标杆值、偏差或等级差距、达标状态和数据来源，不直接承担主数据维护。

## 菜单位置

- 首页工作台：在 `/home` 的「能源运营」区域点击「能效对标」进入。
- 侧边栏：进入「能源运营 / 能效对标」，打开 `/energy/benchmark`。
- 标准库维护：进入「能源运营 / 对标配置」，打开 `/data/energy-benchmark`。

## 查询条件

进入 `/energy/benchmark` 后，先设置报告期，再选择标准库类型、标准方案、对象层级、指标和对象编码。对象层级支持基地总体、区域、用能系统、设备类型、设备、产线/工序和产品。

{{evidence:EV-WH-126}}

常用查询组合如下：

1. 设备运行能效：对象层级选择「设备」，指标选择「单位运行小时用电」。
2. 用能系统效率：对象层级选择「用能系统」，指标选择「单位作业量用电」。
3. 基地总体能效：对象层级选择「基地总体」，指标选择「单位面积用电量」或「单位面积综合能耗」。
4. 产品/产值强度：对象层级选择「产品」，指标选择「单位产品综合能耗」或「单位产值综合能耗」。
5. 设备等级对标：对象层级选择「设备类型」，指标选择「设备能效等级」，标准库选择「设备能效等级库」。

## 指标看板

页面顶部展示对标覆盖率、对标对象数量、超标对象数量、平均偏差和节能潜力。切换期间、对象层级、指标或标准库后，指标随当前筛选条件刷新。

当指标为「设备能效等级」时，页面按等级类指标展示重点设备、待提升设备、最高等级差距和达标设备，不使用能耗节约量口径。

{{evidence:EV-WH-126}}

## 图表分析

页面中部展示四类图表：

1. 偏差排行：按偏差率查看重点偏高对象。
2. 达标等级分布：查看达标、接近预警、明显偏高、缺分母、缺标杆等状态分布。
3. 实际值 vs 标杆趋势：查看月度实际值与标杆值变化。
4. 节能潜力 Top / 待提升设备 Top：强度类指标查看节能潜力排序，设备等级类指标查看等级差距排序。

{{evidence:EV-WH-126}}

## 结果明细

「对标结果」表展示对象、指标、实际值、标杆值、偏差率或等级差距、数据状态和标准来源。用户可按对象查看是否达标，以及当前结果使用的是政策标杆库、设备能效等级库还是企业内部标准库。

{{evidence:EV-WH-126}}

点击「详情」打开明细抽屉。详情中展示计算结果、标准来源、参考标准、适用条件、来源 hash、分子来源、分母来源和数据质量。

{{evidence:EV-WH-126}}

## 数据缺口处理

分析页底部提供标准库、能源数据、设备台账、产量数据和价格台账入口。对标结果出现缺分母、缺标杆或单位不一致时，应回到对应维护页补齐数据或标准项。

{{evidence:EV-WH-126}}

## 操作要点

1. 分析页只查看和筛选结果，不在图表页维护主数据。
2. 实际值来自能源事实、设备运行小时、作业量、面积、产量或价格等数据。
3. 标杆值来自政策标杆库、设备能效等级库或企业内部标准库。
4. 缺少能源数据、分母数据或标杆值时，系统展示数据状态，不用企业总能耗代替细分对象结果。
