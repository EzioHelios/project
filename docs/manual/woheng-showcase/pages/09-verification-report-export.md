# 核查材料引用

核查材料用于围绕已发布的组织温室气体盘查报告归集凭证、核查工作、问题处理和审核日志。盘查报告的生成、版本管理和导出在「核算报告」页面完成，核查材料包只引用已发布报告。

## 碳核查支撑工作台

进入 `/carbon/verification`，选择核查项目，查看核查项目状态、证据资料、核查工作、质量问题和审核日志。

{{evidence:EV-WH-034}}

## 核查凭证与材料

切换到「证据资料」页签，查看凭证清单、凭证数、文件和下载入口。该页面用于说明活动数据与凭证资料之间的关联。

{{evidence:EV-WH-037}}

## 检查项

1. 先选择真实核查项目，再展示证据和报告。
2. 核查项目应绑定已发布的盘查报告。
3. 凭证清单应能说明文件、活动数据和核查工作的关联。
