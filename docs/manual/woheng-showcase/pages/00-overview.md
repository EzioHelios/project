# 沃衡汽车能碳管理平台操作手册

本手册说明沃衡汽车能碳管理平台的日常操作。使用前，请在页面左下角确认当前生产基地；泰州生产基地和湖州生产基地的数据分别维护和查询。

建议按以下顺序使用平台：

1. 在「组织档案」维护企业信息和区域，在「设备与测点」维护设备、测点及电表接入。
2. 在「能源运营」维护能源种类、单位换算和能源数据，再查询能耗和分析结果。
3. 在「碳数据填报」维护排放源，并按 ISO 14064-1 分类录入或导入活动数据。
4. 在「因子与口径」核对适用的计算因子，在「碳核算」维护核算边界、执行核算并查看结果。
5. 在「碳核算 / 核算报告」维护和导出组织温室气体盘查报告。

产品碳足迹、供应链碳、监测告警、减排项目和态势大屏分别见对应章节。各章均以当前页面的菜单入口和实际操作为准。
