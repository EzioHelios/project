# 能效平衡

本章说明如何查看能量平衡、数据质量、优化测算和优化记录。能效平衡用于回答“能源输入、有效利用、损耗和优化措施之间的关系是否清晰”。

## 菜单位置

- 首页工作台：在 `/home` 的「能源运营」区域点击「能效平衡」进入。
- 侧边栏：进入「能源运营 / 能效平衡」，打开 `/energy/balance`。

## 平衡与优化

进入 `/energy/balance`，查看平衡简表、数据质量、优化测算和优化记录。该页面用于从能量平衡角度查看输入、有效利用、损耗、平衡差异和来源分布，并可在优化测算页签中选择场景、填写参数、生成测算结果和保存优化记录。

## 操作要点

1. 平衡简表用于查看输入、利用和损耗关系。
2. 数据质量用于辅助判断本期能源数据是否具备分析条件。
3. 优化测算用于形成节能方案测算结果。
4. 优化记录用于保留已形成的优化方案和执行信息。
