# 企业数据来源与组织碳活动数据导入

组织温室气体核算使用当前租户的报告主体、报告期、边界、排放源、活动数据和计算因子。录入前，先在页面左下角确认当前生产基地，再核对 `/data/company` 中的企业基本信息，以及 `/carbon/organization/boundary` 中的报告主体、报告期和已发布边界。不同生产基地的数据分别维护、分别核算。

## 选择数据维护方式

- 电表及其他能源用量在 `/data/energy-consumption` 维护。购入电力的组织碳活动数据在 `/carbon-mgmt/category/2.1` 逐条录入，或使用 2.1 分类模板批量导入。
- 员工通勤资料在 `/data/commute` 维护。员工通勤的组织碳活动数据在 `/carbon-mgmt/category/3.3` 按交通方式、里程和人数录入，或使用 3.3 分类模板导入。
- 燃料、制冷剂、运输、采购和废物等活动，应先确认其来源记录、ISO 二级分类和计量单位，再进入相应分类页面录入或导入。

能源事实录入、编辑和 CSV 导入见“能源运营：能源事实数据维护”。经营活动台账中的记录不会因保存而自动成为已核算排放量；组织碳活动数据还需确认分类、边界归集、计算方法和因子。

## 下载对应分类模板

从分类填报菜单进入目标二级分类，例如 `/carbon-mgmt/category/2.1` 或 `/carbon-mgmt/category/3.3`。确认当前盘查任务和分类后，点击「下载本类模板」；也可点击「导入本类数据」，在导入页面选择盘查期、组织、归集区域、活动分类和计算方法，再点击「下载分类模板」。模板与所选分类、方法绑定，不能把其他分类的文件改名后混用。

## 填写工作簿

先阅读 `00_填报说明`。在 `01_组织与边界`核对盘查任务、组织和设施编号；在 `02_排放源`填写排放源；在 `03_活动数据`填写每条记录的编号、期间、活动量、单位、来源和本分类专有字段。`03A_区域设备归集`按记录编号填写区域、设备或计量边界，归集比例合计为 100%。`04_参数与因子`填写方法要求的参数，活动记录通过参数集编号引用；`05_证据索引`登记已存储文件的信息，`06_数据证据关联`把文件关联到活动或参数。

购入电力的分类字段包括能源种类、供应商、计量点和 Scope 2 方法；员工通勤的分类字段包括运输方式、里程和人数等。以实际来源文件和适用因子为准填写活动量与参数值，单位必须与计算方法相符。证据索引中的文件存储标识应指向已保存的材料；填写文件名本身不等于上传文件。

## 预检、确认导入和回查

在 `/carbon-mgmt/import` 上传 `.xlsx` 文件，点击「执行预检」。分别查看「活动数据」「区域设备归集」「方法与参数」「证据覆盖」「校验问题」五个页签。预检应显示有效记录数，阻断错误为 0；如有警告，核对每一行并填写确认原因。

点击「确认导入」，待状态变为「已入库」。随后点击「活动台账」，按新记录编号搜索，核对活动量、单位、ISO 分类、质量状态和归集结果。预检只检查文件，只有「已入库」和活动台账回显才能说明记录已写入系统。重复导入已存在的记录编号时，应按页面提示先核对原记录，不能把重复报错当成新增成功。

导入完成后，在活动详情中检查因子参数和 100% 区域设备归集；再进入“组织碳核算执行与结果明细”章节执行核算。入库成功不等于核算成功。

## 经营活动台账参考

入库、出库等台账用于保留作业记录。只有明确活动量口径、ISO 分类和计算因子后，相关数据才可进入组织碳活动清单。
