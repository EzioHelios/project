# 组织碳总览与结构分析

本章用于查看组织温室气体核算后的汇总指标、排放结构、趋势变化和追溯路径。边界、排放源、活动数据、因子和报告分别在独立章节维护，本章只说明核算结果的展示和分析。

## 组织碳总览

## ISO 14064 分类查看

进入「碳数据填报 / 分类填报」，通过 ISO 二级分类页面查看和维护活动记录：

1. 类别 1：固定燃烧等直接排放。
2. 类别 2：购入电力等能源间接排放。
3. 类别 3：员工通勤、运输等间接排放。
4. 类别 4：采购商品与服务等间接排放。
5. 类别 5：售出产品相关活动。
6. 类别 6：其他经确认的间接排放。

各分类页面按同一套新增、编辑、详情、归集和删除方式维护本类活动数据。不同分类在表单中显示对应字段，活动数据总账用于跨分类只读查询和追溯。
