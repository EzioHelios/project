# 能源运营操作顺序

能源数据从区域、设备和能源种类开始维护。自动采集的电表数据在设备与测点页面配置；按账期录入的能源事实数据在「能源数据维护」页面维护。两类数据的配置步骤分别见「区域、设备与 MQTT 电表接入」和「能源事实数据维护」。

1. 进入「组织档案 / 监测区域」维护区域层级，再进入「设备与测点 / 设备台账」挂载设备与测点。
2. 进入「能源运营 / 能源种类」「单位换算」核对能源名称、单位和换算关系。
3. 进入「能源运营 / 能源数据维护」新增、导入或修改能源事实记录。
4. 进入「能源运营 / 能耗查询」按期间、区域、设备和能源种类查询记录与汇总。
5. 根据任务进入「能耗强度」「用能分析」「能流分析」「能效对标」或「能效平衡」查看计算结果。

能效对标的标杆方案和指标在「能源运营 / 对标配置」维护；能碳预算及预算维护位于「气候与减碳」。分析页面用于筛选和查看结果，主数据应返回对应维护页面修改。
